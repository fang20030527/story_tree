# 外刊首页视觉样稿

运行：在仓库根目录执行 `node docs/visual-preview/server.mjs`，打开 <http://127.0.0.1:8766>。

这是用于确认视觉方向的单页 HTML 样稿。使用品牌原始 Logo、项目现有的文章与图片，以及本地 Source Serif 4 字体。字体来自 Adobe 的 source-serif 项目，许可证保存在 `assets/SourceSerif4-LICENSE.md`。

可以切换浅深主题、预览宽度、筛选主题、搜索文章、打开文章速览，并在当前页面会话中切换收藏状态。主导航的其他页面会提示本次预览范围。文章摘要为样稿说明文字，展示文案以现有文章主题为依据。

样稿不访问业务 API，不写入用户账户、书架或词库。正式 APP 的界面与逻辑尚未改动。本地服务只暴露明确列出的样稿及图片路径。

`preview.png` 为浏览器中的实际页面截图。已检查 JavaScript 语法、全部静态资源加载、搜索与无结果状态、分类筛选、文章弹层、会话内收藏、浅深主题，以及 390／430 像素手机宽度和宽屏展示。桌面较矮窗口会等比缩放手机画框，手机浏览器则按实际窗口宽度显示。
