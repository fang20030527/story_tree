# 第二版：红粉阅读室

第一版的 HTML、样式、交互脚本、截图和预览服务原样保存在上一级目录。

第二版启动命令：`node docs/visual-preview/v2/server.mjs`。

- 第二版：<http://127.0.0.1:8767/>
- 第一版：<http://127.0.0.1:8766/>，可用 `node docs/visual-preview/server.mjs` 单独启动。

第二版顶部和页脚提供第一版链接。两版使用独立文件与端口，可同时打开对照。

## 视觉变化

豆沙粉成为精读区域的主色面。Instrument Serif 用于英文标题，中文以紧凑黑体建立信息层级；照片向右错开，圆形朱橙按钮表示阅读动作。文章列表使用刊物封面和真实标题，导航保持「外刊／书架／词库／我的」。

字体使用 Google Fonts 仓库中的 Instrument Serif，随附 `assets/InstrumentSerif-OFL.txt`；图标使用项目已经安装的 Ionicons。文章与图片沿用第一版内容，便于对比视觉差异。

页面支持浅深主题、宽度切换、主题筛选、搜索、空结果提示、文章速览、会话内收藏及键盘操作。其他导航入口说明单页样稿范围。样稿不调用业务 API，正式客户端尚未应用这些样式。

## 验证

已通过脚本语法检查与静态资源加载检查，并在浏览器验证分类筛选、搜索命中、无结果状态、文章速览、收藏反馈和浅深主题。已检查 360 像素手机视口及宽屏展示；`preview-mobile.png` 和 `preview.png` 分别保留这两种尺寸的实际截图。
