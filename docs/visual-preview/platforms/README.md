# 黑洞英语：iPad、小程序、Web 原型

基于已确认的 APP「红粉阅读室」版本制作。保留 Logo 配色、刊物素材、英文衬线字、每日精选、双维度筛选、紧凑 VIP 入口与学习日志；按平台调整布局和导航。

## 启动

在仓库根目录运行：

```powershell
node docs/visual-preview/platforms/server.mjs
```

| 版本 | 地址 | 主要适配 |
| --- | --- | --- |
| iPad | <http://127.0.0.1:8769/#home> | 紧凑侧栏、横竖屏切换、宽屏双栏、阅读工具侧栏 |
| 小程序 | <http://127.0.0.1:8770/#home> | 状态栏、顶部胶囊、返回导航、底部标签栏、安全区 |
| Web | <http://127.0.0.1:8771/#home> | 完整侧栏、封面网格、并排统计与日志、阅读工具侧栏 |

原 APP 原型继续使用 `node docs/visual-preview/app/server.mjs`，地址为 <http://127.0.0.1:8768/#profile>。最初的第一版和第二版保持独立。

顶部下拉框可直接查看全部 29 页。「页面总览」展示所有页面入口；iPad 顶部可切换横竖屏。小程序胶囊中的菜单可打开指南与设置，圆形按钮返回首页。小屏时使用下拉框查看其他页面。

四端顶部均显示「手机 / iPad / 小程序 / Web」切换入口；切换保留当前路由（包括文章与练习编号），可以在同一页面比较不同布局。

## 页面与交互

每个版本包含全部 29 页：外刊、文章介绍、阅读、书架、最近阅读、收藏；词库、单词列表、智能及自定义选词、生成、主题短文、阅读、自测、结果；五种导入方式及处理与预览；个人页、设置、登录、重置密码、指南、VIP。

三端共用 `../app/` 的内容与交互控制器。`platform.js` 负责各平台导航和阅读侧栏，`platform.css` 负责布局。手机控制器仅增加页面渲染与弹层事件，原手机界面不改变。

- 每日精选独立于主题、刊物和搜索；筛选只更新发现列表。
- 每日精选整张色块（含箭头、图片、标题和空白）进入文章介绍页；收藏按钮单独操作，介绍页点击「开始阅读」进入正文。
- 阅读侧栏提供译文、字号和本篇词汇查词；窄屏保留正文中的阅读工具。
- 学习日志点选日期及键盘切换可查看当日详情。
- 智能选词不展示具体词，自定义选词支持勾选与确认；可继续体验四篇短文和自测。
- 导入可填入示例、预览、编辑标题并加入书架。
- VIP 支持套餐切换、方案确认及邀请码兑换，示例邀请码为 `READ30`。

## 验证与边界

浏览器检查三端全部路由，并覆盖 iPad 1194 × 834 横屏、820 × 1180 竖屏，小程序 390 × 844 浅色、360 × 780 深色，Web 1440 × 900 及窄屏布局。检查正文与页面的横向溢出、导航、弹层与资源加载。

实际操作验证了外刊筛选不改变精选、iPad 侧栏字号与译文、查词弹层、小程序菜单与返回、日志日期与键盘选择、VIP 年度价格及邀请码兑换、自定义选词至短文生成，以及粘贴正文至书架的导入流程。

这是独立 HTML 交互原型，尚未迁移到 Expo、微信小程序工程或正式网站。状态仅保存在页面内存，刷新后恢复；不访问真实账号、数据库、支付、AI 服务或上传文件。未运行生产工作区和数据库测试。
