## 可以体验的交互

- 顶部「手机 / iPad / 小程序 / Web」可往返切换四端原型，切换保留当前页面；小屏同样显示全部版本入口。
- 左上角「我的」标题与模式入口合并：标题旁显示当前「阅读／口语」标记和下拉箭头，点击整组标题展开模式菜单，选择后收起。切换后仍停留在「我的」，同时切换底部导航、学习统计、学习日志和内容入口。菜单支持上下方向键、Home／End 和 Enter 选择；Escape 返回标题，点击外部或 Tab 离开时收起。当前模式同时通过文字、颜色、选中勾和无障碍属性表达。
- 阅读模式主导航为「外刊／书架／词库／我的」；口语模式为「素材／文件／我的」。口语模式「素材」展示平台跟读内容、分类与素材介绍；「文件」展示个人音视频、继续跟读、音频／视频筛选和导入入口。iPad、Web 的侧栏主导航随模式更新，小程序使用对应底部导航。
- 口语「素材／文件」页复用阅读页的公共品牌栏，保留原 Logo 与「黑洞英语」字标。点击 Logo 返回当前模式首页：阅读为外刊，口语为素材；栏目标题位于品牌栏下方。
- 影子跟读参考用户提供的竞品功能，沿用原有红粉设计：上方音视频预览与当前句字幕，中间双语时间轴和句子工具，底部固定播放控制。音频显示波形，视频使用原创示例封面，可以展开播放器。
- 字幕工具支持自动滚动、句子收藏与收藏筛选、逐句／段落显示、当前句讲解、素材词汇、中文或英文搜索定位，以及英文、中文和时间范围编辑。编辑阻止空英文、无效时间及相邻字幕重叠，保存后同步到预览和字幕列表。
- 底部可上一句／下一句、播放／暂停、拖动进度、选择 0.5×–1.5× 速度、逐句复读或 AB 范围复读、跳过空白。设置中选择复读次数、句间停顿和字幕字号；逐句和 AB 复读互斥，跳出 AB 范围会关闭 AB。
- 字幕显示支持双语、仅英文、仅中文与关闭；遮挡板隐藏文本，点选句子后揭开。录音演示开始、停止、回放与重录，录音回放就绪后显示在固定控制区。通过「更多」或右上角菜单完成练习，当前网页内增加一条示例跟读记录。
- 跟读文件导入支持音频、视频两条示例路径，以及「自动生成字幕／使用已有字幕」选择；预览页可逐句修改英文字幕，空内容会提示补充。保存后进入跟读页，修改的英文内容同步到练习，示例文件加入「文件」列表。

- 外刊精选、书架继续阅读、词库复习三个大色块以点按为主：触点暖白柔光扩散，按住轻压、松手回弹，箭头短促前移。悬停不触发；移动超过 9px、滚动、移出、系统取消或窗口失焦时清除反馈，不阻止原生滚动。快速点按也会显示反馈，入口在 110ms 后执行原操作，不等待整段动画；支持键盘触发与系统减少动态效果设置。
- 顶部「每日精选」为独立推荐位，切换主题、刊物或搜索均不改变其内容。原型固定展示猫科物种文章，尚未接入每日推荐服务。
- 精选色块的箭头、图片、标题、说明和空白区域统一进入文章介绍页；收藏按钮独立操作，介绍页点击「开始阅读」才进入正文。
- 每日精选下方「发现文章」提供主题与外刊两行并列筛选，BBC Future 归入 BBC；主题、刊物和搜索取交集，仅局部更新下方内容并保留筛选位置。列表包含全部匹配文章，精选文章排在列表末尾。
- 搜索支持英文标题、中文标题、刊物和主题，清除搜索保留已选刊物与主题；无结果时可清除当前刊物内的筛选，或返回全部外刊。
- 收藏与取消收藏、书架分类与空状态。
- 「我的」页学习记录下方新增学习日志，按本地日期展示最近 13 周、每周七行的热力图。红粉色阶表示每日学习时长：无记录、1–10 分钟、11–20 分钟、21–30 分钟、30 分钟以上；未来日期留空。点选日期查看阅读篇数、复习词数与学习分钟，支持键盘上下切换相邻日期、左右切换同一星期几，并显示区间内学习天数和当前连续学习天数。
- 正文查词弹层、加入词库、标记掌握、展开译文、调整字号与深浅色主题。
- 智能选词：不展示具体单词，按示例到期安排自动选词，只能在待复习数量内设置本次词数；无待复习词时展示空状态。
- 自定义选词：从词库勾选、全部选择、确认后生成；使用全部确认词，修改未确认就返回时不覆盖原选择。模式之间切换会保留自定义选择。
- 生成状态与失败重试、四个主题、三道语境题和实际作答结果。
- 正文长度与链接格式校验、示例文件选择、电脑上传状态、处理失败、编辑导入标题和加入书架。
- 示例登录、微信授权入口示意、验证码与重置成功状态、清空示例阅读历史。
- VIP 页以「读得懂，也说得出」呈现阅读与口语共用权益，套餐选择前置。月度／年度／永久三档单选，切换后同步更新价格、期限和每日均价；开通按钮固定在底部。Web 使用上方品牌与套餐并排、下方权益列表的布局。
- 「阅读权益／口语权益」默认展示进入订阅页时的当前模式，切换介绍不会改变产品模式或套餐选择。阅读保留智能阅读陪练、AI 语境查词、长难句拆解与专业语音朗读四项；口语加入台词 AI 讲解、录音跟读、无级变速、字幕切换、台词笔记与句子收藏、字幕内词典查词、单句循环七项，以及视频离线下载、PDF 台词本、App 内 YouTube 视频、TED 演讲变速四项拓展卖点。拓展权益集中标为「规划中」，说明上线后开放。权益切换栏滚动时保持可见，支持左右方向键、Home／End、焦点与选中状态。
- 开通确认、订阅说明与兑换成功页同步显示阅读和口语共用权益。页头「兑换」与底部「邀请码兑换」打开相同输入弹层，支持空值、无效码、兑换成功与重复兑换反馈。可点击「填入示例邀请码」或输入 `READ30` 体验 30 天 VIP 的兑换效果；支持小写与首尾空格，Enter 提交。示例兑换状态仅保存在网页内存，不开通真实权益。
- 支持 Escape 关闭弹层、弹层内 Tab 焦点循环和键盘操作。

## 原型边界

这是用于审阅视觉、布局与交互的独立 HTML 原型，还没有迁移到 Expo 客户端。当前模式通过 URL 的 `mode=speak` 参数保留，刷新与切换四端原型时继续显示该模式；练习进度、导入文件、字幕修改、录音状态等只存在于当前网页内存，刷新后恢复示例。

学习日志根据日期生成固定示例；共 12 个有阅读记录的日期，与个人页已读篇数示例保持一致。记录不来自真实账号，也不会随原型里的阅读操作自动累加。

口语模式使用独立的示例素材、文件、练习记录和学习日志。账号、设置和 VIP 入口共用。口语模式的学习日志也是固定示例，不随「完成」操作重新生成；个人页练习次数与累计分钟会根据当前示例记录更新。

新版跟读播放以计时器模拟进度、字幕同步、变速与复读，不播放真实音视频；视频区域是原创示例封面。录音操作只切换界面状态，不申请麦克风权限，不录制或输出真实声音。字幕导入、自动生成和自动分段使用预置内容；讲解与词汇为配套示例，不调用 AI 服务。收藏、编辑、练习设置和录音状态都只保留在网页内存；本版不包含 AI 发音评分或纠错。

不调用 API，不上传文件，不抓取输入的网址，不发送邮件，不写入账号或数据库。密码只进行本地格式校验，随后清空，不存储。阅读正文、翻译、练习与导入结果是固定示例；朗读只演示播放控件，不输出音频。生成页通过「查看完成效果」直接切换状态。智能选词使用固定的到期标记模拟记忆曲线安排，尚未接入真实 FSRS；自定义确认后的词数会传递到生成与主题页面，示例正文不随选词重新生成。

文章标题与图片使用仓库现有素材，示例正文不声称是刊物原文。VIP 入口改为紧凑横条，移除独立的「VIP 版」大标题，保留「升级为 VIP 版，解锁全部功能／立即开通」文案，点击进入订阅页。价格暂参考用户提供的竞品图片：月度 ¥19（30 天）、年度 ¥128（365 天）、永久 ¥198（长期有效），划线价为 ¥30／¥199／¥399。价格、优惠与不限次数权益均为原型示例，实际产品方案待确认；点击开通只展示确认弹层，不发起支付、不扣款、不改变账号权益。旧的 `#pro` 链接会跳转到 `#vip`。

本次订阅改版只扩充权益文案与展示交互。跟读页仍演示 0.5×–1.5× 五档速度，讲解使用预置内容；没有实现连续变速、AI 台词服务、台词笔记、字幕词典、离线下载、PDF 导出或外部视频来源接入。AI 发音评分与纠错继续不在当前范围内。
