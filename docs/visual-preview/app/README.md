# 黑洞英语：第二版完整页面原型

用户选定「红粉阅读室」方向后扩展的可点击原型。朱橙、豆沙粉来自现有 Logo，英文标题延续 Instrument Serif；长文正文使用本地 Source Serif 4。

## 打开

在仓库根目录运行：

```powershell
node docs/visual-preview/app/server.mjs
```

- 页面总览：<http://127.0.0.1:8768/#gallery>
- 原第二版首页：<http://127.0.0.1:8767/>
- 原第一版首页：<http://127.0.0.1:8766/>

原第一版和第二版文件未修改。完整原型读取第二版基础样式与字体，使用独立服务、脚本和扩展样式。服务只监听本机。

## 可以体验的交互

- 顶部「手机 / iPad / 小程序 / Web」可往返切换四端原型，切换保留当前页面；小屏同样显示全部版本入口。

- 外刊精选、书架继续阅读、词库复习三个大色块以点按为主：触点暖白柔光扩散，按住轻压、松手回弹，箭头短促前移。悬停不触发；移动超过 9px、滚动、移出、系统取消或窗口失焦时清除反馈，不阻止原生滚动。快速点按也会显示反馈，入口在 110ms 后执行原操作，不等待整段动画；支持键盘触发与系统减少动态效果设置。
- 顶部「每日精选」为独立推荐位，切换主题、刊物或搜索均不改变其内容。原型固定展示猫科物种文章，尚未接入每日推荐服务。
- 精选色块的箭头、图片、标题、说明和空白区域统一进入文章介绍页；收藏按钮独立操作，介绍页点击「开始阅读」才进入正文。
- 每日精选下方「发现文章」提供主题与外刊两行并列筛选，BBC Future 归入 BBC；主题、刊物和搜索取交集，仅局部更新下方内容并保留筛选位置。列表包含全部匹配文章，精选文章排在列表末尾。
- 搜索支持英文标题、中文标题、刊物和主题，清除搜索保留已选刊物与主题；无结果时可清除当前刊物内的筛选，或返回全部外刊。
- 收藏与取消收藏、书架分类与空状态。
- 「我的」页学习记录下方新增学习日志，按本地日期展示最近 13 周、每周七行的热力图。红粉色阶表示每日学习时长：无记录、1–10 分钟、11–20 分钟、21–30 分钟、30 分钟以上；未来日期留空。点选日期查看阅读篇数、复习词数与学习分钟，支持键盘上下切换相邻日期、左右切换同一星期几，并显示区间内学习天数和当前连续学习天数。
- 正文查词弹层、加入词库、标记掌握、展开译文、调整字号与深浅色主题。
- 智能选词：不展示具体单词，按示例到期安排自动选词，只能在待复习数量内设置本次词数；无待复习词时展示空状态。
- 自定义选词：从词库勾选、全部选择、确认后生成；使用全部确认词，修改未确认就返回时不覆盖原选择。模式之间切换会保留自定义选择。
- 生成状态与失败重试、四个主题、三道语境题和实际作答结果。
- 正文长度与链接格式校验、示例文件选择、电脑上传状态、处理失败、编辑导入标题和加入书架。
- 示例登录、微信授权入口示意、验证码与重置成功状态、清空示例阅读历史。
- VIP 订阅页展示智能阅读陪练、AI 语境查词、长难句拆解、专业语音朗读四项权益；月度／年度／永久三档单选，切换后同步更新价格、期限和每日均价。支持点按整张套餐卡与键盘方向键；开通按钮进入方案确认，订阅说明解释有效期与不自动续费的规则。
- 订阅页底部「邀请码兑换」打开输入弹层，支持空值、无效码、兑换成功与重复兑换反馈。可点击「填入示例邀请码」或输入 `READ30` 体验 30 天 VIP 的兑换效果；支持小写与首尾空格，Enter 提交。示例兑换状态仅保存在网页内存，不开通真实权益。
- 支持 Escape 关闭弹层、弹层内 Tab 焦点循环和键盘操作。

## 原型边界

这是用于审阅视觉、布局与交互的独立 HTML 原型，还没有迁移到 Expo 客户端。所有状态只存在于当前网页内存，刷新后恢复。

学习日志根据日期生成固定示例；共 12 个有阅读记录的日期，与个人页已读篇数示例保持一致。记录不来自真实账号，也不会随原型里的阅读操作自动累加。

不调用 API，不上传文件，不抓取输入的网址，不发送邮件，不写入账号或数据库。密码只进行本地格式校验，随后清空，不存储。阅读正文、翻译、练习与导入结果是固定示例；朗读只演示播放控件，不输出音频。生成页通过「查看完成效果」直接切换状态。智能选词使用固定的到期标记模拟记忆曲线安排，尚未接入真实 FSRS；自定义确认后的词数会传递到生成与主题页面，示例正文不随选词重新生成。

文章标题与图片使用仓库现有素材，示例正文不声称是刊物原文。VIP 入口改为紧凑横条，移除独立的「VIP 版」大标题，保留「升级为 VIP 版，解锁全部功能／立即开通」文案，点击进入订阅页。价格暂参考用户提供的竞品图片：月度 ¥19（30 天）、年度 ¥128（365 天）、永久 ¥198（长期有效），划线价为 ¥30／¥199／¥399。价格、优惠与不限次数权益均为原型示例，实际产品方案待确认；点击开通只展示确认弹层，不发起支付、不扣款、不改变账号权益。旧的 `#pro` 链接会跳转到 `#vip`。

- 四端切换在 320 与 390 像素宽度检查了全部版本入口、选中状态与横向溢出；实际验证手机 → iPad → Web → 小程序 → 手机，保留个人页与文章概述路由。

- 所有 JavaScript 模块通过 `node --check`。
- 29 个页面在 360 × 800 视口完成渲染检查：没有页面级或正文区域的横向溢出。
- 实际在浏览器操作：词库 → 练习 → 查词 → 自测（答对、答错、不确定）→ 结果；粘贴正文 → 校验 → 处理 → 编辑标题 → 书架。
- 检查了示例登录与重置密码、深色主题、页面总览、空状态和失败重试。
- 浏览器没有脚本错误；服务白名单内的资源正常返回。
- 外刊改版检查了刊物、主题、关键词的组合，以及每日精选不随筛选变化、无结果恢复和搜索清除后保留筛选。
- 色块动效在浏览器检查了三页点按、快速连续点按仅保留一个反馈层、拖动取消且不误跳转、反馈结束后自动清理，以及阅读／练习入口和键盘激活。
- VIP 页在 390 × 844 浅色与 360 × 800 深色视口检查了布局与横向溢出；验证了三档套餐切换、¥0.63／¥0.35 每日均价、永久套餐说明、方案确认、订阅说明、Escape 关闭和「我的」页入口。浏览器未报告脚本警告或错误。
- 邀请码兑换验证了入口、空值与无效码提示、示例填入、Enter 提交、成功及重复兑换状态；360 × 800 深色弹层没有横向溢出，关闭后恢复订阅页。
- 学习日志检查了 390 × 844 浅色和 360 × 800 深色布局，没有横向溢出；日期空记录、当日记录、键盘切换、选中状态和唯一 Tab 入口正常。

此变更仅新增独立原型，没有改动生产客户端或服务端，因此没有运行会连接数据库的全仓检查。
