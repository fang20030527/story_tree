# 口语素材口音标注

素材列表、精选卡片、详情页和影子跟读页统一显示口音。当前 10 份平台素材均已标注；未知平台素材及用户导入文件显示「口音：待确认」，避免依据标题、文件名或演员国籍猜测。

| 素材 | 标签 |
| --- | --- |
| 乔布斯、库克、黄仁勋、丹泽尔毕业演讲 | 美式 |
| 特朗普就职演讲、西点毕业演讲 | 美式 |
| 罗琳哈佛毕业演讲 | 英式 |
| 阿甘正传 | 美式（美国南部） |
| 泰坦尼克号 | 美式 / 英式 |
| 奥德赛 · The Odyssey | 美式为主 |

标签集中维护于 `app/src/features/speaking/accents.ts`，按素材 ID 和平台来源匹配，不改变 API 契约、字幕或播放数据。新素材上线时需要同时维护标签；新增澳式等口音时使用对应中文标签。

## 判定依据与范围

- 演讲按演讲者在当前录音中的发音归类。对 6 份演讲各截取 45 秒，以及 3 部电影分别截取 3 段 45 秒音频，使用已有 EvoLink / Gemini 音频能力辅助核对广义口音；乔布斯演讲另依据原录音的已知美式发音。辅助结果仅采用广义类别，不采用模型推测的地区和族裔。
- 罗琳的哈佛演讲也列于 [Sadaspeak 英式口音练习](https://sadaspeak.com/en/british-accent-practice/)。
- 泰坦尼克号包含美式主角对白及英式等配角对白，标为混合；温斯莱特在 [BAFTA 本人访谈](https://www.bafta.org/media-centre/press-releases/bafta-a-life-in-pictures-kate-winslet/)中谈及从泰坦尼克号开始与美式方言教练合作，因此不能按演员本人国籍把露丝对白标为英式。
- 阿甘包含美国南部发音特点，仍归入美式。The Odyssey 的标签依据当前本地视频片段判断为美式为主，不从目录年份推断影片版本。
- 标签用于跟读选材，是素材级提示，并不保证整部影片所有角色只使用该口音；目前未运行实时口音识别或对私人导入文件上传分析。

## 验证

提交前执行根目录 `npm run check`，并导出生产 Web；上线后核对素材卡片、详情页和跟读页的口音文本及窄屏换行。
