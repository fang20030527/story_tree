# 口语固定资源 R2 迁移

2026-10-01，用户授权配置 R2 并迁移三部已有字幕电影，明确它们属于所有用户可见的口语「素材」，不放入任何个人「文件」。

## 当前配置

- 复用项目已有、经过真实读写验证的 R2 凭证，已安全写入忽略提交的 `app/.env`，服务端切换为 `SPEAKING_STORAGE_DRIVER=r2`。另持久化播放签名密钥；客户端变量和构建不包含这些凭证。
- 使用私有 Standard 桶 `waikan-2026-audio`。原有外刊音频保持 `audio/`；电影使用 `speaking/platform/<素材 ID>/<SHA-256>/source.mp4`，原始外挂字幕也保存为同目录的 `source.srt`。
- 桶原先没有 CORS 策略。通过已登录的 Wrangler OAuth 配置一条只读规则，允许实际本地 Expo Web 来源、`https://blackholeenglish.com` 和现有 Web Worker 域名的 GET／HEAD／Range；没有打开桶公共访问。
- 服务端发布清单位于 `server/content/speaking/cloud-catalog.json`。公开目录与详情只返回素材摘要或字幕；播放器申请十分钟的私有 R2 预签名 URL，客户端会提前续期并恢复播放位置。

总计 3,746,314,922 字节视频（约 3.75 GB／3.49 GiB）、5,046 句字幕。源目录为用户指定的 `D:\qBittorrent\下载`，源电影与字幕只读保留。《星际穿越》没有外置字幕，也没有可抽取的内嵌字幕，本次没有上传。

迁移使用流式 multipart，每段 8 MiB；SHA-256 对象键可安全重跑，已完整上传且元数据匹配的对象不重复上传。发布之前核对实际媒体、字幕时长与数量、R2 完整大小，以及头／中／尾各 64 KiB 与源文件的一致性。

三部影片和三份原始 SRT 已完整保存，另保存一份带内容哈希的目录快照。原子发布成功时间为北京时间 2026-10-01 09:39。最终桶清点为 2,732 个对象、12,131,200,731 字节（约 12.13 GB）；原有 2,725 个对象保留，新增加七个对象。

## 使用与部署

当前本地 Fastify API `http://127.0.0.1:3000` 和真实 Expo Web `http://127.0.0.1:8081` 已接入。口语「素材」增加「电影对白」分类；游客可以查看原字幕和播放，笔记、校正、进度与练习记录保存在设备。已登录用户仍按账号保存自己的字幕覆盖、笔记、录音和记录。固定影片不占个人上传配额。

上述迁移验收完成时，配置与新增接口作用于本地 Fastify 和前端源码。随后用户授权推送 main 并部署 Web，已将口语接口适配到正式 Cloudflare Worker 与 D1，继续使用同一私有桶；没有把 Neon 写入混到 D1。正式发布进度见 [阅读与口语 Web 发布报告](2026-10-01-speaking-web-release.md)。

## 验证记录

真实 R2 小型验证对象的上传、读取、签名 Range 206 和 CORS 通过，验证对象已删除。未签名请求被 R2 S3 endpoint 拒绝（HTTP 400）；没有启用公共访问。

服务端相关 8 个测试文件／73 项（含两个隔离数据库集成流程）、客户端完整 84 套／414 项、契约完整 50 项通过。全工作区 TypeScript 与 Lint 通过，Lint 保留 24 条原有客户端警告；播放器修复后再次通过客户端与服务端 TypeScript、相关客户端 ESLint。服务端构建、修复后的 39 条 Web 路由导出，以及 830 个客户端文件／6 项实际服务端密钥的泄漏检查通过。

本地 API 重启后，未登录请求可读取六份固定素材（原有三份示范音加三部电影）。三片公开详情的字幕数量、时长、平台来源通过共享契约校验；三片播放接口均返回 `no-store`，十分钟签名地址的真实 Range 206／CORS 通过。Neon 中个人口语文件和素材仍为零条。

真实浏览器已验证三片出现在口语「素材／电影对白」，Logo 与「素材、文件、我的」导航保留。《阿甘正传》按第四句定位到 201.559 秒后持续播放至 273.078702 秒，视频就绪、无媒体错误，暂停有效。验收中修复了重复播放状态引起的 React 更新循环、Web 轮询清理和播放器重渲染关联问题；修复后新一轮浏览器错误日志为空，并新增实际 Expo SDK Web hook、VideoView 与 HTML 视频节点回归。
