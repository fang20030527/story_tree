# 黑洞英语正式前端交付

本次实现范围为 iPhone、iPad、Web 和独立微信小程序工程，暂不开发 Android。`docs/visual-preview/` 中已确认的各版原型完整保留。

## 查看与启动

当前运行的正式 Web 前端：<http://127.0.0.1:8780/>。这是 Expo 客户端，随窗口宽度使用手机底部导航、iPad 侧栏或桌面双栏；原型中的设备切换控件不属于正式产品。

重新启动时，在仓库根目录执行 `npm run dev:app`。若需要固定 Web 端口，在 `app/` 中执行：

```powershell
node ../node_modules/expo/bin/cli start --web --port 8780
```

iPhone/iPad 使用同一 Expo 工程，已启用 `supportsTablet` 和横竖屏适配，构建平台限定为 `ios`、`web`。原生微信登录模块需要包含原生模块的开发或签名构建；本地原生调试需要 macOS/Xcode，真机验证需要设备。真机 API origin 使用可访问的局域网或 HTTPS 地址，不能使用电脑的 `localhost`。

微信小程序导入 `miniprogram/`，构建、自己的 AppID 和合法域名配置见 [小程序说明](../miniprogram/README.md)。不要把原型 HTML 当作小程序，也不要直接导入构建后的 `dist/` 目录。

## 已完成

- 品牌配色、本地字体、触控反馈、浅深主题和响应式导航；原生凭据仍使用 SecureStore，Web 使用标签页会话存储。
- 外刊每日精选固定，整张色块进入概述；主题、外刊和年份筛选只影响下方发现内容，保留搜索、分页和刊期浏览。
- 书架“导入”文字入口、实际最近阅读；词库取消加号，待复习海报与三列居中真实统计。
- 我的页面紧凑 VIP 入口、真实账号、近期阅读、云端单词统计、最近 13 周学习日志；缺失统计显示“—”，不填演示值。
- 智能选词交由服务端 FSRS；自定义选词支持实际词库多选、编辑与创建练习，保留幂等提交和额度错误。
- 阅读、查词、练习、自测、导入、登录和设置沿用真实业务，统一颜色与内容宽度。
- 19 个原生微信小程序页面，共享 API 契约；包含公共文章、词库、练习任务轮询、自测、翻译、文件及电脑上传导入、邮箱登录、本机学习日志。

书架收藏、最近阅读和学习时长目前属于设备本地记录；云端词库、导入文章和练习使用现有账号数据。VIP 权益与方案页面、邀请码入口已经制作，支付及兑换接口尚不存在，按钮明确显示未开放，不扣费或模拟成功。
