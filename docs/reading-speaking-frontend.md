# 阅读与口语前端交付说明

已将确认的原型迁入 `app/src` 的 Expo 客户端。原型 HTML 仍保留在 `docs/visual-preview/app`；实际客户端使用 React Native 组件、expo-router 和真实媒体 API。

## 运行与入口

在仓库根目录运行 `npm run dev:app`，或在 `app` 目录运行 `node ../node_modules/expo/bin/cli start --web --port 8081`。当前本机开发服务已经启动。

| 页面 | 当前 Web 地址 |
| --- | --- |
| 我的与模式切换 | http://127.0.0.1:8081/profile |
| 口语素材 | http://127.0.0.1:8081/（先在我的切换口语） |
| 我的口语文件 | http://127.0.0.1:8081/shelf（口语模式） |
| 跟读示范 | http://127.0.0.1:8081/speaking/shadowing?id=curiosity |
| 文件导入 | http://127.0.0.1:8081/speaking/import |
| VIP | http://127.0.0.1:8081/pro 或 /vip |

实际客户端使用路径路由，无需原型的 `#vip` 或 `?mode=speak` 参数。

## 已实现

- 我的标题与模式按钮结合，显示「阅读／口语」，切换后留在我的；选择保存在当前设备。阅读为外刊、书架、词库、我的；口语为素材、文件、我的。桌面使用侧边导航。
- 口语素材与文件沿用品牌 Logo、暖白／深墨、朱橙、豆沙粉和既有字体。分类、搜索、详情、文件筛选、空状态与继续跟读使用真实数据。
- 三组原创短练习配美式合成示范音，字幕时间根据生成音频测量，页面注明音源。`scripts/generate-speaking-fixtures.ps1` 可重新生成；`app/assets/speaking/curiosity.srt` 可用于导入验证。
- 已登录账号可导入带字幕的真实音视频，最多 3 GB；未登录可继续使用本地文件，最多 100 MB，不自动创建匿名账号或代替用户确认年龄。SRT／VTT 字幕最多 512 KB，支持 UTF-8 与 Windows-1252 电影字幕。字幕编辑校验开始时间顺序、非空内容及已知媒体时长，允许不同说话者重叠；长电影每页编辑 20 句，可按句号跳转。
- Expo Audio／Video 提供真实播放、暂停、上下句、进度定位、倍速、逐句与 AB 复读。支持重复次数、停顿、跳过空白、自动滚动、分段、字幕四种显示、遮挡与揭开、查找。
- 收藏句子、台词笔记及字幕点词查询可用。查词复用现有离线词典；内置讲解明确标注为素材配套注释。
- 点击开始录音才申请麦克风权限。录音暂停原音，可停止保存、回放、重录；云素材录音上传后保存到账号，个人本地素材录音保留在设备；失败保留录音并提供重试，没有 AI 发音评分或纠错。
- 练习只累计播放、录音或回放的实际时间。播放期间定期保存，暂停、完成和路由离开时保存；同一次练习重复保存不会产生多条历史。个人页显示真实统计，初始为零。
- VIP 按 2026-10-01 确认的渠道定价展示：网页端月度 ¥19、年度 ¥128、永久 ¥198；苹果端月度 ¥22、年度 ¥148、永久 ¥228。iOS 原生 App 展示苹果价，Web（含 iPhone 浏览器）展示网页价，Android 保留原价。套餐卡片、所选金额、每日均价与订阅说明使用同一份渠道配置；均为单次购买，不自动续费。阅读 4 项、口语 11 项权益，两端一致。浏览权益不会改变学习模式。
- 功能概览与口语指南说明当前可用功能和服务状态。

## 数据与实现位置

- `app/src/context/LearningModeContext.tsx`：模式及恢复时的并发保护。
- `app/src/app/(tabs)`：按模式切换标签、图标与页面组件。
- `app/src/features/speaking`：素材、导入、字幕、播放器、录音和练习记录。
- `app/src/features/subscription`：套餐、权益、说明与兑换状态。
- `speakingStorage.ts`：缓存元数据按账号隔离；未登录使用本机 guest 空间，串行写入。旧本地文件和历史继续保留。新云素材经共享契约和 `/v1/speaking` 上传、读取，`cloudSync.ts` 处理字幕、收藏、笔记、录音和练习状态同步、版本检查与幂等重试。
- `app/src/api/speaking.ts`：原生用 Expo SDK 57 `File.upload` 发送二进制，Web 直接发送所选 File／Blob；不会 Base64 编码或把整片电影读入 JS 内存。上传失败可重试同一资产；字幕保存丢失响应时复用原请求和幂等键。播放地址从服务器领取短期凭证，过期更新，不在媒体 URL 拼接身份令牌。
- 文件库每页读取 20 份素材摘要，列表显示 `cueCount`，可加载更多并保留旧缓存；打开详情、字幕校正或跟读页时单独读取完整字幕与最新练习状态，避免一次获取多部电影的全部字幕。摘要中的空字幕不作为字幕修改提交。
- 云电影的完整字幕只缓存当前一部，元数据与文件列表不重复存放字幕；切换电影会重新读取对应字幕。旧本地文件和本地字幕保持原样，避免多部电影扩大单个 AsyncStorage 缓存值。跟读列表使用虚拟列表，字幕分段和筛选不随每次播放进度更新重复计算。
- `app/app.json`：录音权限配置。已有原生开发构建需重新生成、安装，使权限改动生效。

已登录账号的新云素材、字幕、录音与练习记录可以跨设备同步；已有本机记录仍保留。云同步失败明确显示失败及重试，不生成已同步状态。当前仍不接入自动字幕识别、AI 发音评分或真实支付。服务端存储与测试说明见 [口语后端说明](speaking-backend.md)。
