# 口语多来源导入

口语「文件」与「导入跟读文件」增加六种入口，沿用现有音视频上传、账号文件库、字幕校正与跟读流程。

| 来源 | 操作与范围 |
| --- | --- |
| 网盘 | 打开系统文件选择器，从 iCloud Drive 或已安装且支持系统文件提供商的网盘选择音视频；未接入系统文件的网盘也可通过分享导入。 |
| 相册 | 手机通过系统照片选择器选视频，使用原始文件，避免额外转码；Web 通过视频文件选择器选择。 |
| 网页链接 | 下载公开音视频地址，或解析网页里的 audio、video、source 和媒体元数据；下载后沿用文件上传流程。 |
| 本地 | 选择本地音频或视频，支持 MP3、M4A、WAV、AAC、OGG、MP4、MOV、M4V 和 WebM。 |
| 电脑 | 复制网页上传地址，在电脑登录与手机相同的邮箱账号，上传媒体和字幕；手机刷新账号文件库后继续跟读。Web 可直接选择当前电脑的文件。 |
| 其他 App | iOS／Android 系统分享接收一份音视频，可同时附带一份 SRT／VTT，也支持单独字幕或网页链接；缓存复制完成后清除系统分享数据。 |

## 字幕与保存

所有来源都支持 SRT／VTT 外挂字幕和手动填写时间、英文字幕。手动添加至少一句后，云端文件也可以保存。保存成功进入原有字幕校正页，再开始跟读。自动语音识别仍未开放。

本地保存限制 100 MiB，账号文件上传沿用 3 GiB 上限。网页媒体下载单独限制 100 MiB 和三分钟，避免客户端临时内存占用过大；较大的媒体使用本地、网盘或电脑上传。网页导入不处理需要登录、DRM 或只有 HLS／DASH 播放列表的页面。

选择取消、下载失败和保存失败不会创建虚假的成功记录。云端保存继续使用已有幂等键与上传检查点，响应丢失后重试不重复上传。下载和上传可以取消；分享或下载产生的临时副本在离开导入页时释放，源文件保留。

## 服务端

新增 `POST /v1/speaking/remote-media`，JSON 请求由共享 `SpeakingRemoteMediaRequestSchema` 校验，成功返回经实际文件头校验的二进制媒体流。接口需要安装身份、现有限流与来源校验，不保存网页 URL，也不返回上游 Cookie、文件名或其他响应头。

Fastify 每次连接、重定向及网页媒体链接都复用现有 DNS 校验与解析结果锁定。Cloudflare 复用项目已有 Workers 出站策略，在每次请求之前拒绝 IP 地址、私网形式主机名、凭据与异常端口，再依赖 Workers 出站代理限制内部服务。HTML 只解析，不执行脚本；HTML 大小最多 1 MiB，重定向最多五次，媒体流持续校验大小、取消与实际传输长度。

不需要数据库迁移或新增存储服务。网页下载后仍由现有媒体上传逻辑校验实际格式、时长和账号容量。

## 构建与配置

系统分享接收通过 Expo SDK 57 自带的 `expo-sharing` 配置插件注册 iOS 扩展和 Android Intent Filter，`+native-intent.ts` 将分享事件路由到口语导入。更改原生配置后，需要重新构建并安装手机 App；Expo Go 与现有旧安装包不会自动出现新的系统分享目标。Web 的本地、链接和电脑上传可随前端及 API 更新使用。

`plugins/withSpeakingSharing.js` 在注册分享扩展时选取一个回调 scheme，避免 SDK 57 插件将主应用的 scheme 数组写入仅接受字符串的原生字段；主应用仍保留原有微信回调。测试会生成并检查真实的扩展 Info.plist 与 Android strings 配置。

可选的 `EXPO_PUBLIC_WEB_BASE_URL` 指定手机展示的电脑上传网站，默认 `https://blackholeenglish.com`；Web 展示当前页面来源，便于本地与测试环境验证。

参考 SDK 57 官方文档：[分享接收](https://docs.expo.dev/versions/v57.0.0/sdk/sharing/)、[系统文件选择](https://docs.expo.dev/versions/v57.0.0/sdk/document-picker/)、[相册选择](https://docs.expo.dev/versions/v57.0.0/sdk/imagepicker/)。
