# 指定账号无限练习次数

## 处理结果

2026-09-27 已在生产 D1 中为用户指定的注册账号开启永久练习次数豁免，覆盖普通练习和四主题练习。设置绑定服务端用户身份，现有安装包无需重新打包。没有改动登录凭据、历史学习内容或其他账号的额度。

## 实现

- 增量迁移 `0004_user_practice_access.sql` 新增账号级开关，没有权限记录的账号继续执行免费额度规则。
- 登录、首页、练习创建和练习详情共用额度读取逻辑；创建批次的原子 SQL 同时检查账号开关，允许已用完三次额度的豁免账号继续创建。
- 保留 reserve/commit/release 账本和幂等规则；旧客户端的整数额度字段使用 `Number.MAX_SAFE_INTEGER` 作为兼容标记，实际授权由数据库布尔开关控制。
- 运维脚本 `scripts/set-practice-access.mjs` 按邮箱查找唯一有效注册账号，写入时再次校验归属并回读验证，支持 `--unlimited` 和 `--limited`。凭据只读取环境变量。

## 验证与发布

Cloudflare API 7 个测试文件、35 项测试通过，其中新增的 5 项隔离 D1 测试覆盖额度耗尽后继续创建、四主题创建、重复请求、失败释放、撤销豁免，以及其他账号和已删除账号的限制。API 类型检查、Worker 打包检查通过。

启动现有本地测试数据库后，全工作区 `npm run check` 通过：客户端 386 项、服务端 292 项、契约 33 项，共 711 项测试；类型检查和 lint 无错误，保留已有 24 条 lint 警告。测试使用本机隔离 Schema，没有执行真实 AI 生成。

生产迁移已成功执行，`waikan-api` 发布版本为 `0d19bec9-8f86-4cb0-a9f6-5ee531580161`。2026-09-27 10:33（北京时间）回读确认：只有指定账号开启豁免；原账本合计仍为 -3；共用额度读取函数返回无限兼容标记；服务健康检查返回 200，未登录首页 API 返回 401。

仅修改指定账号的练习次数权限。身份验证、账号隔离、请求频率和单次输入约束继续生效。账号授权与回读凭证保存在忽略提交的 `.local-test-results/`，文档和脚本不保存用户邮箱、密码或访问令牌。
