# 口语固定素材封面与占位清理

从共享素材库下架 `curiosity`、`conversation`、`small-steps` 三个原型占位练习，清空服务端示范目录并移除客户端附带的示范音和字幕。客户端素材合并时过滤三个旧 ID，使旧安装缓存也不会重新显示占位内容；真实视频缓存和个人练习记录保留。

## 检查与发布

全工作区类型检查和 lint 通过；客户端 87 个套件、443 个测试通过。口语目录 14 个单元测试通过，数据库集成测试首次触发 30 秒超时，单独提高测试超时重跑后通过，实际用时 18.78 秒。回归测试覆盖旧缓存占位隐藏及真实视频离线缓存。

生产 Web 导出完成，十张导出封面的字节与源 JPEG 一致，发布包未包含检查的七项服务端密钥值。发布前备份原 R2 摘要目录；新版 Web 版本为 `2785dd6d-4d68-49b3-b9f0-2ecec2322d7b`。

原视频和原型时期的 R2 发布对象没有物理删除；共享目录移除占位条目，可通过备份恢复。

线上核验通过：公开目录只返回十个真实视频，共 6,865 句字幕；三项占位素材详情均返回 404，十份真实素材详情与原字幕清单一致。十张正式封面均返回 JPEG，SHA-256 与源图一致。浏览器确认全部封面成功解码，演讲筛选返回七项、电影筛选返回三项，电影详情页封面正常显示。
