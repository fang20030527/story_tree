# 2026-10-05 全面审查与修复

本轮审查覆盖线上 Cloudflare Worker（`cloudflare/api`）、共享的服务端模块（出题、校验、复习排期）、契约包和 Expo 客户端。下面是已修复的问题和需要产品决策的事项。

## 已修复

| 问题 | 影响 | 修复 |
| --- | --- | --- |
| Worker 没有实现 `POST /v1/practices/:id/retry-failed` | 四篇主题短文中有文章生成失败时，「重试未生成的短文」按钮一直返回「服务暂时不可用」。9 月 25 日迁移到 Cloudflare 时只迁了读取接口里的 `canRetryFailed`，漏了写接口 | 新增 `cloudflare/api/src/practice/retry-failed.ts`，规则与原 Fastify 实现一致：至少一篇已就绪、只补可重试的失败原因、每篇只补一次、不额外扣次数；D1 批处理用 `transaction_guards` 防止并发重复排队 |
| 未知的 `/v1/*` 路由返回可重试的 503 | 客户端会一直重试，也掩盖了上面漏迁的路由 | 改为不可重试的 404 `NOT_FOUND` |
| 自测题干缺 `____` 或带中文时直接放行 | 客户端 `isEnglishSelfTest` 判定失败，按旧版释义题显示：题目上方直接显示目标词（答案），还高亮原文位置 | 校验器去掉题干和选项里的中文注释；题干没有空格时先在目标词的任一词形处挖空，仍不行则改用原文句子挖空，追加题则不出；随机损坏草稿的模糊测试加入这两条不变式 |
| 从词库创建单篇练习时目标写入超出 D1 每条语句 100 个绑定参数 | 目标词 ≥ 20 时批处理被拒，返回可重试的「练习创建暂时不可用」，永远无法成功 | 目标写入按 15 行拆分成多条语句，最终的计数校验不变 |
| `requireAuth` 每个请求都写 `last_seen_at` | 每个 API 请求多消耗一次 D1 写入（免费额度每天 10 万行），而该字段从未被读取 | 改为一次读取校验身份，`last_seen_at` 最多每 15 分钟刷新一次，刷新失败不影响请求 |
| 访客有学习记录时登录已有邮箱账号被拒，提示「请先完成账号合并」 | 产品没有合并功能，访客也看不到退出按钮，只能卸载重装 | 登录页遇到 `AUTH_ACCOUNT_CONFLICT` 时说明游客记录无法合并，用户确认后改用新的空游客身份登录 |
| 登录和注册共用一个表单 | 邮箱输错时静默创建一个空账号，用户以为数据丢了 | 服务端返回 201 时提示「已创建新账号」并显示所用邮箱 |
| Web 端 `Alert.alert` 是空函数 | Web 版无法删除导入文章、无法清空最近观看，书架「更多操作」无反应 | 新增 `confirmAction`／`notify`，Web 用浏览器对话框，原生端行为不变 |
| 客户端从不显示剩余免费练习次数 | 用户只能在点「开始」失败后才知道额度用完 | 练习设置页显示剩余次数；用完时说明情况，不再显示必然失败的开始按钮；无限额度账号不显示 |
| 自测每答一题都重新加载整篇练习 | 每题之间多一次完整请求（文章、全部题目、分组、额度），经香港中转时更明显 | 用答题接口返回的结果在本地推进到下一题，只有拿不到结果时才回退为重新加载 |
| 设置页版本号写死为 0.1.0 | 显示错误版本 | 读取 `expoConfig.version` |
| `app/src/data/mock.ts` 大部分为未使用的演示数据 | 维护负担 | 只保留实际使用的导入来源，移到 `features/imports/importSources.ts` |

## 需要决策的事项

第 1–5 项和下面前两条建议已在 [账号合规、每日额度、留言审核与加载速度](2026-10-05-account-quota-moderation.md) 中处理，第 6 项的苹果内购方案也写在那里。

1. **免费额度是终身 3 次**：所有账号（包括注册用户）总共只能生成 3 组练习，VIP 暂未开放购买，用完后间隔重复的核心循环就停了。建议改成按天或按周恢复的免费额度。
2. **没有注销账号功能**：App Store 审核指南 5.1.1(v) 要求支持注册的 App 提供应用内删除账号；也没有隐私政策入口（5.1.1(i)，以及《个人信息保护法》）。
3. **留言瓶是公开的用户内容**，没有举报、屏蔽和审核（审核指南 1.2）；用户改名后旧名字可被他人注册，旧留言仍显示旧名，可被冒用。
4. **生词不能删除或修改**：录错的释义会一直用于出题，只能标记为已掌握来隐藏。
5. **AI 成本没有总量上限**：游客身份可无限创建，网页端每开一个新标签页就是新游客和新的 3 次额度；同步翻译接口单次可达 1 万字符。建议按 IP 或设备限制每日新游客和 AI 调用量。
6. **iOS 版展示不可购买的 VIP 价格页**，可能被审核认为是占位内容。

## 其他建议（未改动）

- 词库列表和首页每次请求都把用户全部单词、全部语境和全部答题记录读进内存计算，词量上千后会逼近 Workers 免费版 10 ms CPU 和 D1 每日读取额度。建议把下次复习时间、答题数等存成列，用 SQL 排序分页。
- 每个请求的限流都写一次 D1；可评估 Workers Rate Limiting 绑定。
- 主题短文中同一个词出现在多篇文章时，每篇都算一次 FSRS 复习，词少时会在几分钟内连续复习 3–4 次，拉长间隔。可考虑按 `topic_group_id` 合并。
- `server/assets/editorial/epub` 有 17,164 张插图（约 1.3 GB）提交在 Git 里，仓库包体积 1.34 GiB；线上已由 `waikan-images` 提供。
- Fastify／Neon 后端已不承载线上流量，但出题、答题、复习逻辑仍需两边同步维护；建议把共享的纯逻辑抽成独立包，逐步下线 Fastify 业务模块。
