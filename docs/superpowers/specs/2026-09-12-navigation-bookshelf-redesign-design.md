# 外刊与书架信息架构改版设计

**日期：** 2026-09-12  
**状态：** 待书面规格复核  
**范围：** 重构 Expo 客户端的外刊发现、文章概述、书架和导入入口，并为私人导入文章补齐列表与永久删除 API。

## 1. 背景

当前底部导航同时存在“阅读”和“外刊”。“阅读”包含平台文章、书籍、活动和 AI 长文练习；“外刊”同时包含导入、每日快讯、Kid News 和学习讨论。两个入口都在展示可阅读内容，且导入、收藏与内容发现没有稳定边界。

本次改版把底部导航调整为：

1. **外刊**：发现和浏览平台提供的外刊内容；
2. **书架**：导入文章并管理用户主动保留的内容；
3. **词库**：管理具体词义并创建 AI 长文练习；
4. **我的**：账户、订阅、学习统计、最近阅读、设置与帮助。

改版继续使用当前 Expo Router、React Native、AsyncStorage、Fastify、Drizzle 和 PostgreSQL 架构。平台外刊继续使用前端模拟数据；本次不建设内容管理后台。

## 2. 目标

- 消除“阅读”和“外刊”的职责重叠；
- 让用户明确区分“发现内容”与“管理自己的内容”；
- 所有平台外刊先进入文章概述，再由用户选择直接阅读或加入书架；
- 让五种导入方式和已导入文章在“书架”页形成完整闭环；
- 用明确的文字按钮表达“加入书架”，不要求用户理解抽象 bookmark 图标；
- 保留现有文章导入、私人正文阅读与翻译流程；
- 为书架补齐用户全部导入文章的服务端列表，以及经过确认的永久删除能力；
- 不丢失现有私人导入文章、词库条目、学习进度或最近阅读记录。

## 3. 非目标

本次不包括：

- 平台外刊 CMS、运营后台、发布 API 或跨设备同步；
- 平台外刊正文、书架状态或阅读历史的服务端存储；
- 书籍、活动或学习讨论的新页面设计；
- 私人文章回收站、软删除或删除恢复；
- 删除文章时同步删除已独立进入词库的词义或学习证据；
- 改造 AI 长文练习的生成、答题或计费逻辑；
- 笔记、复杂标注、离线下载或公开分享；
- 将私人导入文章也强制经过新的平台文章概述页。

现有“书籍”“活动”“学习讨论”在这次主导航改版中隐藏，但不删除其模拟数据，以免引入无关清理。

## 4. 已确认的产品决策

- 第一个底部入口命名为“外刊”，不使用“阅读”“发现”或“今日”；
- 第二个底部入口命名为“书架”；
- “加入书架”取代现有“收藏”，不保留两个相近概念；
- 平台外刊必须由用户主动加入书架；直接阅读不会自动加入；
- 用户确认导入文章后，该文章自动成为书架内容；
- “我的收藏”从“我的”页移除，旧路由改为跳转书架；
- 最近阅读继续位于“我的”，其含义是“读过什么”，不等同于“主动保留什么”；
- AI 长文练习入口只保留在词库页；当前词库页已有“创建长文练习”按钮，外刊页删除重复入口；
- 私人导入文章可以从书架永久删除；不采用仅本地隐藏；
- 平台外刊继续使用前端模拟数据，私人导入文章使用真实后端数据。

## 5. 顶层信息架构

### 5.1 外刊

外刊页只负责平台内容发现：

- 今日精选；
- 精选外刊；
- 每日快讯；
- Kid News；
- 平台模拟目录搜索。

首页不再展示导入控件、用户书架、AI 长文练习、书籍、活动或学习讨论。所有可见文章卡片使用同一跳转规则：先打开文章概述页。

### 5.2 书架

书架页只负责两类任务：

- 导入外部资源；
- 浏览和管理用户内容。

页面从上到下包含：

1. “导入文章”卡片，直接展示网页链接、粘贴正文、相册、本地文件和电脑上传五个入口；
2. “我的书架”标题和管理入口；
3. “全部 / 平台外刊 / 我的导入”筛选；
4. 统一的文章列表。

平台外刊条目显示封面、来源、标题、词数、预计时长和加入时间。私人导入条目显示来源类型、标题、词数和导入时间。平台外刊条目点击后回到概述页；私人导入条目直接打开现有私人文章阅读页。

### 5.3 词库

词库继续展示义项状态和到期情况。当前页面已有“创建长文练习”按钮，因此只需确保旧外刊首页不再重复展示同一入口。

### 5.4 我的

“我的”保留账户、订阅、统计、最近阅读、功能介绍和设置。“我的收藏”入口移除。旧 `/favorites` 路由跳转到书架，避免旧链接或已打开页面失效。

## 6. 核心用户流程

### 6.1 发现并阅读平台外刊

```text
外刊首页
  → 点击文章卡片
  → 文章概述
  → 点击“开始阅读”
  → 平台文章阅读页
  → 写入最近阅读，但不改变书架
```

### 6.2 保存平台外刊

```text
文章概述
  → 点击“加入书架”
  → 本地持久化成功
  → 按钮变为“✓ 已加入”
  → 短暂提示“已加入书架”
  → 书架立即可见该文章
```

再次点击“✓ 已加入”会移出书架。若持久化失败，按钮恢复原状态并显示可重试提示。

### 6.3 导入私人文章

```text
书架
  → 选择五种导入方式之一
  → 沿用现有处理与可编辑预览流程
  → 用户确认
  → 服务端创建私人文章
  → 打开私人文章阅读页
  → 文章通过服务端列表自动出现在书架
```

书架不需要为私人导入文章另存一份本地收藏状态。服务端 `imported_articles` 是其唯一真实来源。

### 6.4 永久删除私人文章

```text
书架私人文章行
  → 更多菜单
  → “删除文章”
  → 确认弹窗
  → DELETE /v1/articles/:id
  → 服务端事务删除
  → 收到 204 后从书架移除
```

确认文案必须说明：“正文和翻译将永久删除，无法恢复；已加入词库的词义和学习进度会保留。”客户端不做先删后请求的乐观更新，避免请求失败时出现假删除。

## 7. 页面与交互设计

### 7.1 外刊首页

- 顶部居中显示“外刊”，保留搜索入口；点击后展开输入框，并按中英文标题、来源和分类对完整的本地模拟目录进行过滤；
- 今日精选使用大图卡片；
- 其他栏目沿用当前红色竖条标题和“更多”入口；
- 合并当前 `index.tsx` 的精选文章与 `feed.tsx` 的每日快讯、Kid News；
- 每张卡片都提供来源、难度或阅读时长等足够的选择信息；
- 卡片点击区域整体可访问，`accessibilityLabel` 包含标题和“查看文章概述”。

### 7.2 平台文章概述页

概述页包含：

- 返回按钮；
- 封面图；
- 封面右上角的文字按钮“加入书架”；
- 来源、分类、中英文标题；
- 词数、预计阅读时间、难度；
- “文章概述”和“你将读到”；
- 底部固定主按钮“开始阅读”。

加入成功后，右上角按钮变为黄色的“✓ 已加入”。按钮保持文字表达，不单独使用 bookmark 图形。阅读按钮与书架按钮相互独立。

### 7.3 书架页

- 顶部只显示居中的“书架”标题；本次不增加搜索，避免对尚未加载的服务端分页数据产生不完整结果；
- 五个导入入口全部直接展示，不折叠进“更多”；
- 列表默认按加入或导入时间倒序；
- 筛选只影响列表，不隐藏导入卡片；
- 平台外刊的更多菜单提供“移出书架”；
- 私人导入文章的更多菜单提供红色“删除文章”；
- 空书架仍显示导入卡片，并提供“去外刊看看”的次级空状态动作；
- 服务端导入列表加载失败时，已保存在本机的平台外刊继续显示；“我的导入”区域显示独立错误和重试按钮。

### 7.4 阅读页

平台文章使用独立的模拟数据阅读路由，不调用私人文章 API。私人导入文章继续使用现有 `/article-read` 路由和翻译能力。

现有私人阅读页右上角的星标收藏移除，因为私人文章已经天然属于书架。其“导入新文章”加号也移除，导入职责回到书架页。

## 8. 客户端组件边界

实现应把当前两个体积较大的 tab 页面拆成职责明确的单元：

- `features/editorial/catalog`：规范化平台模拟文章数据；
- `features/editorial/EditorialHomeScreen`：组合外刊首页栏目；
- `features/editorial/EditorialOverviewScreen`：文章概述与书架按钮；
- `features/editorial/EditorialReadScreen`：模拟平台正文阅读；
- `features/shelf/editorialShelfStorage`：仅存平台文章 ID 和加入时间；
- `features/shelf/ShelfScreen`：合并平台书架与服务端私人文章列表；
- `features/shelf/ImportSourceGrid`：复用五种导入入口；
- `features/shelf/ShelfRow`：根据条目类型渲染操作；
- `api/articles`：私人文章列表、读取和删除请求。

底部路由使用语义名称：`index` 对应外刊，新增 `shelf` 对应书架。旧 `feed` 页面内容被拆分后删除，不作为隐藏的第五个 tab 保留。

共享组件接收经过验证的模型，不直接读取 AsyncStorage 或调用 API。屏幕或专用 hooks 负责加载、合并、重试和导航。

## 9. 平台模拟文章模型

当前 `heroArticle`、`pastArticles`、`newsItems` 和 `kidNewsItems` 应规范化为同一个 `EditorialArticle` 模型，至少包含：

- `id`：稳定的非 UUID 字符串；
- `titleZh`、`titleEn`；
- `summaryZh`；
- `keyPointsZh`；
- `source`、`category`；
- `wordCount`、`minutes`、`level`；
- `image`；
- `section`；
- `publishedAt`；
- `paragraphs`。

本次模拟数据中的每张可点击卡片必须存在对应概述和正文，不能跳到空页面。找不到 ID 时展示“文章不存在”状态和返回动作。

## 10. 本地书架与阅读历史

### 10.1 平台书架

新增版本化 AsyncStorage key `context_reader_editorial_shelf_v1`。每条记录只保存：

- `articleId`；
- `addedAt`。

标题、图片等展示信息始终从当前平台目录按 ID 解析，避免在多个存储位置复制模拟内容。读取时使用 Zod 校验、去重、过滤目录中已经不存在的 ID，并按 `addedAt` 倒序返回。

### 10.2 私人导入文章

私人导入文章不再依赖现有 `FAVORITES_KEY`。所有服务端已确认文章都通过新列表 API 出现在书架，因此旧收藏中的私人文章不会丢失；它们原本就在服务端文章表中。

旧 `FAVORITES_KEY` 保留一个版本周期但不再读取或写入，避免本次改版执行破坏性本地清理。后续版本可以删除该废弃 key。

### 10.3 最近阅读

最近阅读扩展为平台文章和私人导入文章的判别联合类型。现有记录迁移为 `kind: imported`；平台阅读记录保存 `kind: editorial` 和目录 ID。迁移必须可重复执行、去重，并在损坏数据时安全回退为空列表。

## 11. 私人文章列表 API

新增：

```http
GET /v1/articles?limit=30&cursor=<opaque>
```

响应为：

```ts
type ImportedArticleSummary = {
  id: string;
  sourceKind: ArticleImportSourceKind;
  sourceUrl: string | null;
  title: string;
  wordCount: number;
  importedAt: string;
};

type ImportedArticlePage = {
  items: ImportedArticleSummary[];
  nextCursor: string | null;
};
```

规则：

- 必须认证；
- 只返回当前用户文章；
- 默认 30 条，最大 100 条；
- 按 `(created_at desc, id desc)` 稳定排序；
- cursor 是服务端生成的 opaque 游标；
- 摘要不返回正文段落或翻译；
- 契约定义在共享 contracts 包中并由客户端再次解析。

书架首屏加载第一页；滚动到底部时再加载后续页。重新聚焦书架时刷新第一页，并按 ID 合并，避免重复。

## 12. 私人文章永久删除 API

新增：

```http
DELETE /v1/articles/:id
```

成功返回 `204 No Content`。请求必须认证，UUID 格式无效返回 `400`。不存在、已经删除或不属于当前用户的有效 UUID 都返回 `204`，使重试具备幂等性且不泄露其他用户文章是否存在。

### 12.1 数据库外键

新增显式迁移：

- `article_imports.article_id` 改为 `ON DELETE CASCADE`；
- `imported_articles.previous_version_id` 改为 `ON DELETE SET NULL`。

已有外键保持：

- 删除 `imported_articles` 级联删除 `article_paragraphs`；
- 删除 `imported_articles` 级联删除 `article_translations`；
- 删除 `article_imports` 级联删除与其关联的 `computer_upload_sessions` 和 `import_assets`。

迁移不得删除现有数据，并须兼容当前已确认导入记录的约束。

### 12.2 删除事务

服务层在一个事务中：

1. 按 `articleId + userId` 锁定文章；找不到时直接完成；
2. 收集关联 `article_translations.id` 和 `article_imports.id`；
3. 删除这些资源对应的 `article_translation` 和 `article_import` job 行，包括运行中和终态任务；
4. 删除 `imported_articles`；
5. 依赖数据库外键级联删除正文、翻译和导入记录，并把后续版本的 `previous_version_id` 置空。

运行中的翻译 worker 在下一次续租或持久化前失去 job lease 并中止；它不能重新创建已经删除的翻译或文章。服务端不得仅删除书架展示记录而保留正文副本，因为 `article_imports.preview_text` 也含有完整内容。

删除文章不会删除 `vocabulary_items`、`learning_progress`、练习文章或答题证据。当前数据库并未让这些对象外键依赖私人文章；已经提取的来源句会作为独立学习记录继续存在。

## 13. 错误与边界状态

- **平台书架写入失败：** 恢复原按钮状态，显示“暂时无法更新书架，请重试”；
- **目录 ID 无效：** 展示文章不存在页面，不崩溃也不生成虚假条目；
- **平台图片失败：** 使用现有 `RemoteImage` 占位能力，标题和操作保持可用；
- **私人文章列表失败：** 保留平台书架，单独显示云端文章加载失败和重试；
- **删除失败：** 私人文章继续显示，菜单恢复可操作状态；
- **删除中的重复点击：** 禁用该行删除动作，只发出一个请求；
- **文章在其他设备已删除：** DELETE 返回 204，本机正常移除；
- **阅读期间被删除：** 后续读取或翻译返回 404，页面提示文章已删除并返回书架；
- **空书架：** 保留导入入口，并展示“去外刊看看”；
- **本地存储损坏：** 忽略无法解析的记录，不影响私人文章列表。

- 平台书架添加、移除、去重、排序和损坏数据处理；
- 最近阅读旧数据迁移以及平台/私人文章联合记录；
- 底部导航显示“外刊 / 书架 / 词库 / 我的”；

- “加入书架”成功后变成“✓ 已加入”；
- 写入失败时按钮回滚并显示错误；
- “开始阅读”不会改变书架；
- 书架筛选、合并顺序、分页去重和局部加载错误；
- 私人文章删除确认、重复点击保护、成功移除和失败保留；
- 私人阅读页不再显示星标收藏和导入加号；
- “我的收藏”入口移除，旧收藏路由跳转书架。

### 14.2 服务端集成测试

- 列表只返回当前用户文章，并稳定分页；
- 非认证请求被拒绝；
- 删除本人文章返回 204；
- 删除他人或不存在的有效 UUID 返回 204 且数据不变；
- 无效 UUID 返回 400；
- 重复删除幂等；
- 删除级联清理段落、翻译、所有关联导入记录、电脑上传记录和相关 job；
- 删除旧版本只把后续版本的 `previous_version_id` 置空，不删除后续版本；
- 删除不影响词库、学习进度和练习记录；
- 运行中翻译任务失去 lease 后不能重新写入数据；
- 数据库迁移在已有确认文章和版本链上安全执行。

## 15. 完成判定

满足以下条件才算完成：

- 底部导航和四个页面职责符合本设计；
