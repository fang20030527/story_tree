# 黑洞英语：阅读／口语模式与影子跟读原型

日期：2026-09-30
状态：依据用户最新要求完成可交互原型，供界面与流程审阅。

## 本次目标

基于本地最新版红粉阅读室前端增加「口语」模式。在「我的」页顶部放置模式切换，明确显示当前是在「阅读」还是「口语」，切换后主导航立即使用对应结构。阅读继续使用现有外刊体系；口语模式以影子跟读为中心，拥有独立的素材、文件与练习记录。

模式名称按用户最新要求使用「阅读」和「口语」。首版暂不做 AI 发音评分与纠错。素材同时支持平台提供和用户导入；导入时有字幕则使用，没有字幕则自动生成并允许校正。

## 「我的」与导航

根据用户后续反馈，模式入口与左上角「我的」标题合并，不再占据独立一行。标题组合为「我的＋阅读／口语标记＋下拉箭头」，整组为可点击入口，右侧继续显示设置。阅读标记使用豆沙粉，口语标记使用浅朱橙底与朱橙字。

点击标题展开就地菜单，两项分别为「阅读：外刊阅读 · 词汇积累」和「口语：影子跟读 · 开口表达」，配书本、麦克风图标。当前项有浅粉底和勾选图标，选择后菜单收起。点击外部、Tab 离开或 Escape 均可收起；上下方向键、Home／End 移动焦点，Enter 选择，选择或 Escape 后焦点恢复到标题入口。按钮通过 `aria-expanded` 表达展开状态，菜单项通过 `aria-checked` 表达当前模式。

切换时仍停留在「我的」。账户、登录、设置、VIP 共用；页面中的统计、学习日志与内容入口按当前模式展示。两种模式分别保留示例练习数据，切换不覆盖另一模式的数据。

| 模式 | 主导航 | 「我的」统计 | 主要内容入口 |
| --- | --- | --- | --- |
| 阅读 | 外刊／书架／词库／我的 | 已读文章、词库单词、已掌握 | 最近阅读、收藏、阅读练习、文章导入 |
| 口语 | 素材／文件／我的 | 已练素材、练习次数、累计分钟 | 最近跟读、我的文件、跟读素材、文件导入 |

手机与小程序底部导航同步切换为四项或三项；iPad、Web 同步更新侧栏主导航与辅助入口。原型通过 URL 参数保存当前模式，四端跳转和刷新保留模式选择。

## 口语模式页面与流程

| 页面 | 设计与交互 |
| --- | --- |
| 素材 | 豆沙粉「今日跟读」主视觉、原创示例波形、日常表达／访谈对话／演讲片段分类；点击进入素材介绍 |
| 文件 | 继续跟读入口、个人音视频列表、字幕就绪或待校正状态、音频／视频筛选、导入入口 |
| 素材介绍 | 标题、中文介绍、口音、时长、字幕段数、首句预览，进入影子跟读 |
| 影子跟读 | 音视频预览、双语时间轴与句子工具、底部固定播放台；搜索、收藏、讲解、词汇、字幕编辑、逐句／AB 复读、录音与回放 |
| 导入跟读文件 | 选择音频或视频，选择自动生成字幕或已有 SRT／VTT，进入字幕预览 |
| 字幕校正 | 显示每段时间范围，逐句编辑英文；空内容提示补充，保存后进入跟读 |
| 跟读记录 | 显示素材名称、练习段数与分钟，可继续对应练习 |

平台素材路径：素材 → 素材介绍 → 影子跟读 → 完成 → 跟读记录。

个人文件路径：文件 → 导入 → 选择字幕来源 → 逐句校正 → 保存并开始跟读。字幕就绪的文件直接进入跟读，待校正文件先进入校正页。

视觉延续现有暖白底、深墨字、朱橙操作色、豆沙粉色块与细分隔线，英文标题使用现有 Instrument Serif，正文延续 Source Serif 4。练习页面使用「播放器 → 字幕工具与时间轴 → 固定播放台」结构。

素材与文件页共用阅读页的品牌栏，顶部保留原 Logo 和「黑洞英语」字标，栏目标题放在品牌栏下方。点击 Logo 返回当前模式首页，口语回到素材、阅读回到外刊。

## 跟读页的竞品功能适配

依据用户提供的竞品截图调整功能布局，视觉继续使用现有设计系统。播放器采用豆沙粉原创封面或音频波形，当前字幕覆盖其下方；工具按四列两行排列，窄屏保持触点大小。时间轴以英文正文、中文译文和细分隔线呈现，当前句以朱橙边线和浅粉底强调。底部控制固定显示，滚动字幕时可以继续操作。

| 功能区域 | 本次原型交互 |
| --- | --- |
| 播放器 | 播放／暂停、当前句同步字幕、展开／收起；音频与视频分别显示波形与示例封面 |
| 字幕工具 | 自动滚动、收藏与仅看收藏、自动分段、当前句讲解、素材词汇、编辑、查找、更多 |
| 字幕列表 | 序号、开始时间、英中字幕、当前句高亮；点击定位到原音，单句或整段收藏 |
| 字幕编辑 | 修改英文、中文、开始和结束时间；空英文、时间格式、时间顺序和相邻句重叠校验 |
| 播放控制 | 上一句、播放／暂停、下一句、进度拖动、0.5×–1.5× 速度；逐句与 AB 范围复读互斥，越出 AB 范围会关闭 AB |
| 练习设置 | 复读 1／3／5 次或不限次数，停顿 0／1／2 秒，三档字幕字号，跳过空白 |
| 字幕显示 | 中英双语、仅英文、仅中文、关闭；遮挡板隐藏字幕，点选句子后揭开 |
| 录音 | 开始、停止、回放、重录；竞品「录评」按用户要求调整为录音与回放，不含评分纠错 |
| 更多 | 练习设置、跟读指南、跟读记录、完成本次跟读 |

## VIP 订阅页权益扩展

根据用户提供的订阅页截图，将主题改为「读得懂，也说得出」，体现阅读与口语共用 VIP。套餐选择前置，保留现有月度 ¥19／年度 ¥128／永久 ¥198 的原型方案与不自动续费规则。Web 将品牌介绍与套餐并排展示，权益放在下方。

权益按「阅读／口语」切换查看：阅读保留原四项，口语补齐图中的十一项卖点。核心练习包括台词 AI 讲解、录音跟读、无级变速、字幕切换、台词笔记与句子收藏、字幕词典、单句循环；视频离线下载、PDF 台词本、App 内 YouTube 视频和 TED 演讲变速集中显示在「更多学习场景」，标为规划中。进入订阅页时默认显示当前模式的权益，切换介绍不改变产品模式或所选套餐。

权益栏滚动时保持可见，左右方向键与 Home／End 可切换并恢复焦点。页头兑换与底部邀请码兑换共用流程；确认、说明和兑换成功页同步使用阅读与口语权益文案。

本次只扩充订阅原型展示，没有实现新增的连续变速、AI 台词、笔记、词典、离线、PDF 或外部视频服务。当前跟读页仍为预置示例与五档速度；不包含 AI 发音评分与纠错。入口：<http://127.0.0.1:8768/?mode=speak#vip>。

## 交付与边界

原型位于 `docs/visual-preview/app/`，四端共用页面和示例状态。入口：<http://127.0.0.1:8768/?mode=speak#profile>。本次只修改原型及说明，未将功能接入 Expo 或服务端。

所有素材、字幕、文件与练习记录均为本地示例。播放通过计时器模拟进度、字幕同步、倍速和复读，不输出真实音视频；视频使用原创示例封面。录音只演示控件状态，不申请麦克风、不录制声音、不读取或上传真实文件。自动字幕与分段使用预置内容，讲解与词汇是配套示例，不调用识别或 AI 服务。字幕修改、收藏和练习设置保存在当前网页内存。AI 发音评分与纠错不在本版范围内。
