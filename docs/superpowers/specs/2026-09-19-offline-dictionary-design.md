## 数据与查询

生成按词头分片的静态 JSON 和显式加载索引，随 JavaScript 包一起发布。客户端查询不依赖安装令牌、服务器、文件下载或新增原生模块。按需加载分片，避免启动时解析整个词库。精确查询优先，支持大小写、弯引号、词典自带词形链接及保守的常见英语词尾还原；无法匹配时显示“本地词典未收录这个词”，不回退 AI。

兼容现有 `WordTranslationDto`：中文释义最多 200 字，保留完整的简明释义项，词性最多 40 字，音标最多 200 字。多义词按词典顺序显示，并注明本地词典，不宣称语境消歧。
