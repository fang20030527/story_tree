# 词库按单词安排间隔复习

日期：2026-09-14

状态：用户已于 2026-09-14 确认，实施中。

## 用户目标

词库优先呈现更需要复习的单词。复习时间随实际作答和时间流逝变化，避免“复习中”“已掌握”“用户自报已会”这类含义模糊或过度确定的分类。同一单词只有一份复习计划，不要求逐一学完每个释义；文章练习继续围绕该次语境中的具体含义。

## 当前实现及影响

- `vocabulary_items` 按用户、规范化单词和中文释义组合去重，不同释义是独立词条。
- `learning_progress` 按词条累计次数，首次作答后统一改为 `reviewing`，没有下次复习时间。
- 词库列表按收录时间倒序，客户端只对当前已加载数据筛选、计数，因此顶部数字不是完整词库的待复习总数。
- 创建长文练习随机抽取 `pending/reviewing` 词条，不考虑遗忘、上次练习时间，也不保证同一个单词只出现一次。
- 已有首次作答、是否使用辅助及事件时间记录，可以作为间隔复习的输入。

## 可选方案与建议

1. **采用 FSRS 安排单词复习（建议）**：根据复习表现与间隔维护记忆状态，计算下次复习时间。需要增加单词层的数据、调度器和迁移，但能把展示、计数和选词统一起来。
2. **自定逐步延长的时间表**：例如答对后依次延后，答错后缩短。实现简单，但具体间隔是产品规则，对不同单词的适应能力较弱。
3. **只换成“陌生／熟悉”等标签**：工作量小，但不能解决时间流逝、随机抽取和重复计算释义的问题，不足以满足本次目标。

艾宾浩斯的研究描述随时间变化的记忆保持；它不直接给出适合每个人、每个单词的唯一复习日程。常见图示中曲线越低表示记忆保留越少。FSRS 是本方案选择的工程实现，不称为“艾宾浩斯精确公式”。

## 用户看到的变化

### 分类与计数

- 顶部改为“X 个单词待复习”，X 来自服务端完整词库的去重统计。
- 筛选只保留“全部／待复习／未到时间”，默认全部。
- 所有单词都有下次复习时间，新词初始设为收录时刻。“待复习”定义为下次复习时间已到；“未到时间”定义为尚未到期。两个集合互斥并覆盖全部有效单词，新收录的词立即进入待复习。
- 不再将“已掌握”或“用户自报已会”作为永久排除复习的分类。
- 说明文案：“根据练习表现和间隔时间安排复习，优先巩固容易忘的单词。”

### 单词卡片

- 同一个单词只显示一张卡片，展示最近收录的语境含义和例句；更多已保存语境可展开查看，不拆成多个学习任务。
- 未到期词优先显示明确的下次复习时间；已到期词中，从未作答的显示“尚未练习”，上次未独立答对的显示“需要再巩固”，其余显示“到时间复习了”。
- 保留最近练习时间。练习次数和独立答对次数按单词统计，使用辅助的正确答案不算独立答对。
- 不显示未经校准的精确“掌握百分比”，也不使用曲线位置给单词贴永久标签。

例如：bank 的“银行”和“河岸”计为 1 个单词，两种语境保留。一次文章练习只选择其中一个语境使用的含义；答对影响 bank 的下次复习计划，不表示所有含义都已经学会。

## 调度和练习选择

### 记忆模型

- 在服务端封装 FSRS 调度器，保存单词的卡片状态、稳定性、难度、最近复习时间、到期时间、复习次数和遗忘次数；客户端消费展示字段，不重复实现算法。
- 初始使用库的默认参数，目标记忆保留率设为 0.90；这是调度目标，不是实际准确率保证。首版不训练每个用户的独立参数，也不增加算法设置页面。
- 时间以服务端 UTC 为准，客户端按设备时区显示。打开页面、回到前台及到达当前最近的复习时间时刷新，避免只能作答后更新分类。

### 作答如何影响复习

- 首次独立答对：作为成功回忆输入 FSRS（Good），由调度器计算新间隔。
- 首次答错或选择“不认识”：作为回忆失败（Again），由调度器缩短安排；不把“忘记”映射成 Hard。
- 作答前明确查看该目标单词的释义：该次不算独立回忆，首次提交时按 Again 处理。这是保守的产品规则，不能宣称准确测量了用户的记忆。
- 仅查看段落或全文翻译后答对：独立回忆证据不足，不提高记忆强度，也不把整段所有单词直接判成陌生。保持原模型状态，并把下次复习安排到不晚于本次作答后一天；对于本来已经到期或尚未练习的词，安排一天后重新独立验证。
- 上述翻译规则不覆盖明确答错或单词提示：这些情况仍按 Again。
- 单独查看翻译、听发音、阅读原句，不算一次成功复习。回答之后查看帮助不追改已提交的首次答案。
- 同一练习、同一单词只记录一次有效复习；请求重试不能重复累计。已有旧练习若包含一个单词的多个释义，合并该练习内的结果，以较弱的表现为准，从本次练习前状态重新计算，不能连续提升多次。

### 优先级

- 待复习候选池只包含到期词，包括初始就到期的新词；未到期的单词排列在列表后部，默认不进入本次自动选词。仅因翻译辅助被推迟验证的单词也必须到期后再进入候选池。
- 新词缺少回忆记录，作为未知且需要优先学习的独立组；排在到期词之前，不伪造它们的回忆概率。
- 已到期的单词按模型估计的当前回忆概率由低到高排列；相同时按到期时间由早到晚、稳定的单词 ID 排序。未到期词按到期时间排列。
- 词库展示和创建练习复用同一套排序。首版采取严格优先级；新增大量新词时，新词会先于旧词进入练习，这是本方案的明确取舍。
- 创建练习先选去重后的单词，再选该单词最近明确失败的语境；没有失败记录时选最近收录的语境。每个单词只生成一道目标题，不遍历全部释义。
- 新收录同一单词的其他含义只增加语境，不额外增加待复习单词数，也不凭收录动作重置记忆。用户在该语境实际答错时再调整整个单词的计划。
- 生成页文案改成“优先选择需要复习的单词，在文章中练习”，按钮改为“生成长文练习”。
- 数量超过候选池时显示“当前有 X 个单词待复习，请调低练习数量”，不偷偷补入未到期词；待复习为零时显示“当前没有待复习单词”，保留查看全部词库的能力。

## 数据与接口

### 单词和语境分层

- 增加用户级单词实体，唯一键为 `(userId, normalizedTerm)`。沿用现有 NFKC、大小写和空白规范化；本轮不自动合并不同词形，以免把不同单词错误归并。
- 现有 `vocabulary_items` 保留为语境记录，并关联到单词。保留原 ID、释义、例句、练习题引用及历史答案，不直接覆盖或删除其他释义。
- 新的单词复习状态及复习事件以单词为单位。事件同时保留练习和语境引用，便于解释本次练了哪个含义。
- 对首次作答、单词状态更新和事件写入使用同一事务，并锁定单词状态，防止两份练习并发回答丢失更新。

### API 和页面

- 提供按单词分页的读取接口，支持服务端筛选、统一排序和全库统计；旧语境创建接口仍返回语境记录，以兼容文章保存及现有练习链路。
- 新读取响应包含 `wordId`、展示语境、语境数量、复习原因、下次复习时间、单词统计、全库总数和待复习总数。展开语境时再加载额外语境。
- 分类统计与页大小无关；服务端先归并单词、过滤和排序，再分页，禁止在客户端仅归并当前页。
- 游标绑定用户、筛选条件、评估时间及排序字段。同一次分页沿用评估时间以避免纯时间流逝改变排序；单词状态发生写入时使旧游标失效，客户端重新加载第一页。错误不能表现为整个词库为空。
- 首页／个人页等已有词库数量使用同一单词统计定义。旧 `reviewing` 状态不再承担新复习调度的业务判断。

## 旧数据迁移

- 增加表和关联字段，按用户及规范化单词归并；每个有效语境都必须能追溯到唯一单词。
- 根据历史首次答案、练习目标和辅助事件重放单词级复习。同一练习内同词多题按较弱结果合并，保留最早至最晚的练习顺序；时间相同时使用稳定 ID 排序。
- 不从累计正确次数反推不存在的逐次复习结果。没有可用历史的单词初始化为尚未练习；旧累计统计可以保留，但不能据此声称已掌握。
- 旧 `mastered/self_reported` 标签本身不当作独立答对证据，有有效历史则根据历史初始化，没有则等待首次验证。
- 迁移需可重跑，保留历史引用和用户隔离；部署顺序为数据库增量迁移、服务端、客户端。验证迁移前后有效语境和历史答案数量一致。
- 当前工作区另有阅读页、发音和翻译相关未提交改动；实施时需沿用这些改动，不回滚、不覆盖，也不一并提交无关文件。

## 验收

1. 同一用户保存同词两个释义，只增加一个单词计数，两个语境均可访问；不同用户互不影响。
2. 超过一页数据时，顶部总数、分类结果及生成练习的候选数量仍来自完整词库。
3. 固定时间验证：到期边界前后分类正确；更低回忆概率的到期词排在前面；未到期词不被自动抽取；新词遵循明确优先级。
4. 验证独立答对、答错、不认识、单词提示、段落翻译、全文翻译以及答后查看帮助的不同处理。
5. 请求重试、旧练习同词多题、两份练习并发回答不会重复累计或丢失单词状态。
6. 每次文章练习只为每个选中单词选择一个真实保存的语境含义，既有练习能继续打开和作答。
7. 迁移保留释义、例句及历史答案；不伪造旧记录缺少的回忆结果。
8. 客户端覆盖筛选、展开语境、空词库、零待复习、数量不足、分页失败及返回页面刷新；执行相关服务端集成测试、契约测试、客户端测试、类型检查和 lint。

## 依据

- [Murre 与 Dros：艾宾浩斯遗忘曲线复现研究（2015）](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0120644)：支持记忆保持随时间变化的讨论，不提供本产品的单词分类阈值。
- [Cepeda 等：间隔学习与保持时间（2008）](https://laplab.ucsd.edu/articles/Cepeda%20et%20al%202008_psychsci.pdf)：支持复习间隔需要考虑目标保持时间，不能简单视为人人相同的日程。
- [FSRS 算法说明](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm)及 [TypeScript 实现](https://github.com/open-spaced-repetition/ts-fsrs)：本方案调度器的技术依据。
- [Anki 官方复习设置说明](https://docs.ankiweb.net/deck-options)：说明目标保留率与 Again／Hard 的区别。

以上数据模型、辅助信号映射、单词聚合和选词顺序均为本产品设计决定，不是研究结论。
