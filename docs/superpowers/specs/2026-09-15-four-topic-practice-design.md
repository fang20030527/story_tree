# 四主题短文练习

用户已确认：每次生成四个不同主题的短文，每篇 200–300 英文词，生成后展示四个主题板块，由用户决定阅读顺序。主题从经济、文化、政治、科技、教育、环境、社会中不重复选取。

一组含四个独立 practice session，用 topicGroupId、topic、topicPosition 关联；每篇独立保存题目、答案和本地阅读位置。沿用单篇阅读、翻译、答题接口；GET practice 增加可选 group 摘要。旧单篇记录继续可读。

客户端创建请求增加 format: topic_set；旧请求保持兼容。一次事务创建四篇和各自后台任务，只预留一次额度。四篇全部进入终态后，有任意成功则确认额度，全部失败则返还。按组串行锁定状态写入，防止并发结算遗漏。失败短文展示原因，不妨碍选择成功短文。

生成页发现组信息后进入主题选择页，逐步展示生成结果，不自动打开任何文章。选择页刷新和重新进入时恢复服务器状态，完成单篇后返回该组。首页继续入口也导向选择页。

同一组各篇覆盖本次选定词汇，词汇复习仍按现有每次首次答题规则记录。验收包括四个不重复主题、200–300 词验证、独立进度、幂等创建、一次额度、部分和全部失败、越权访问及旧单篇兼容。
