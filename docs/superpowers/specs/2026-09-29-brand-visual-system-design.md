# 黑洞英语 APP 视觉系统提案

日期：2026-09-29
状态：方向已由用户通过多轮原型反馈确认；2026-09-30 进入正式前端实施。

后续范围（2026-09-29）：用户要求先做单页看视觉效果。已据此制作 `docs/visual-preview/` 下的外刊首页可交互样稿，正式客户端视觉改版仍待样稿反馈。

## 目标与依据

让外刊阅读、书架、生词复习和练习流程具有一致的品牌气质。以真实阅读内容、清晰的文字层级和有节奏的留白建立辨识度。

品牌依据为 `app/assets/images/black-hole-english-logo.svg`：朱橙 `#D64727`、豆沙粉 `#E59EB4`、白色 `#FFFFFF`。现有全局主题以金黄为强调色，同时使用蓝色交互和红色栏目装饰，品牌色尚未形成统一规则。

已查看主题、通用组件、四个标签页、登录页、外刊列表及阅读页。当前四个主入口为「外刊／书架／词库／我的」。视觉改版围绕这些已存在的功能展开。

## 方向比较

| 方向 | 具体表现 | 取舍 |
| --- | --- | --- |
| A. 独立阅读刊物（推荐） | 暖白纸色、朱橙交互、少量豆沙粉；英文衬线标题；文章图文分区；列表用细线分隔 | 阅读舒适、适配外刊与生词语境学习，品牌表达更克制 |
| B. 红粉文化海报 | 更大面积的朱橙与豆沙粉拼接、醒目的大字和几何切面 | 品牌第一眼更强烈，长文与高密度词库需要明显收敛 |
| C. 精密阅读工具 | 中性白与深墨色、紧凑列表、极少品牌色 | 操作效率高，品牌温度和视觉记忆相对较弱 |

以下按推荐方向 A 展开，供一次性审阅。

## 色彩系统

| 用途 | 浅色值 | 规则 |
| --- | --- | --- |
| 品牌朱橙 | `#D64727` | Logo、较大强调图形、短指示线 |
| 操作朱橙 | `#BF3D22` | 主按钮、选中导航、文字链接；与品牌色属于同一色相 |
| 品牌豆沙粉 | `#E59EB4` | 登录品牌区、小面积章节标识和复习摘要底色 |
| 纸色背景 | `#FAF7F2` | 页面与长文背景 |
| 浅色表面 | `#FFFCF8` | 输入区、弹层和需要明确容器的内容 |
| 浅粉选区 | `#F7E5EB` | 单词选中、可交互的强调背景 |
| 主文字 | `#27211F` | 标题与正文 |
| 次文字 | `#736761` | 刊物、日期、字数、辅助说明 |
| 分隔线 | `#DED6D0` | 列表与分区边界 |

Logo 朱橙配白字的计算对比度约为 4.38:1；操作朱橙配白字约为 5.38:1。因此实心按钮使用操作朱橙，Logo 本身保持原色。豆沙粉配主文字约为 7.47:1，使用深字。普通大小的文字配色按至少 4.5:1 验收。

背景和文字占主要面积；朱橙用于明确的操作重点，豆沙粉作为少量温和的辅助。错误和成功有独立语义色、图标和文字说明，不能只凭颜色区分。

深色模式使用暖黑 `#191615`、表面 `#24201E`、正文 `#F3EBE4`，可交互文字采用较亮的朱橙 `#ED8C72`。亮朱橙实心按钮配深色文字。Logo 保留原始红粉组合。所有弹层、输入框、空态和禁用状态都随主题适配。

## 字体、间距与形状

- 英文标题和长文采用 Source Serif 4 的常规及半粗字重，作为跨平台一致的阅读字体；字体资源及许可证在实施时随包保存。加载失败时回退到平台衬线字体，页面继续可用。
- 中文导航、说明、表单采用平台中文黑体，保持原生可读性。用字号、字重、行距和对齐建立层级。
- 页面主标题 28–32，文章英文标题 30–34，分区标题 18–20，操作文字 15–16，辅助文字 12–13。英文正文初始值 19／32，并保留已有字号调整能力。
- 手机页面左右留白 20–24；基本间距采用 4、8、12、16、24、32。较宽屏幕的长文限制为易读的内容宽度。
- 普通列表直接排列在背景上，以细线分隔。按钮和输入框圆角 10–12；底部弹层圆角 20；封面圆角 2–6。容器形状按用途区分。
- Logo 放在首页品牌页眉与登录页，以原比例展示，禁止拉伸。它的斜向切面可用于少量品牌区构图，不在长文背后铺装饰。
- 保留统一线性图标与文字标签。点击反馈短而明确，尊重减少动态效果设置。

## 页面设计

### 外刊

顶部为小尺寸 Logo、黑洞英语字标和搜索入口。页内标题「外刊」与栏目之间用留白和细线组织。

今日精选使用一张主封面，标题、刊物、难度和阅读时间排在图像下方。英文标题提供阅读气质，中文标题帮助快速理解；信息不遮挡封面。后续文章采用紧凑图文行，封面比例和元信息位置统一。

继续练习采用单条清晰的续读入口。筛选状态通过文字、细线或浅底明确表达。保留刊物、年份、搜索、分页和下拉刷新交互。

### 书架

页首标题与导入动作形成明确主次。顶部保留全部、平台外刊、我的导入筛选。文章条目按封面、标题、来源和现有进度信息对齐，内容以分隔线组织。

导入入口统一为短标签和线性图标。管理、移除、删除及加载更多沿用现有语义，删除操作保留确认。

### 词库与生词本

词库首页突出实际待复习数量，并给出「开始阅读练习」主操作；总词数与今日新增用一行次级信息表达。豆沙粉用于小面积复习摘要，朱橙用于主按钮。

生词本采用词条列表：英文词、音标、中文释义和复习状态形成稳定层级。既有筛选和状态完整保留，数量继续来自现有接口。零值、未知值与加载值明确区分。

### 阅读、查词与练习

外刊、导入文章、生成练习共用文字与间距规则。正文优先保留足够横向空间，图注弱于正文，章节标题高于正文。

词语选中使用浅粉背景加明确文字状态。查词弹层依次呈现词条、发音、语境释义与加入生词本操作。底部阅读工具栏控制视觉重量，并保留翻译、播放与已有进度能力。

练习创建、生成进度、四主题选择、自测与结果页沿用同一套按钮、分区和状态表现。进度只显示实际状态，不编造百分比。答案正确、错误和选中均有文字或图标说明。

### 我的、登录与辅助页面

「我的」页以学习时长、账户与设置列表组织内容，统计信息与操作入口分层。登录页使用较完整的 Logo 和小面积红粉构图，表单、密码重置、错误提示及键盘避让保持清晰。

导入、预览、处理中、收藏、最近阅读、功能说明和设置同步采用基础视觉规则，保证主要路径之外的页面风格一致。

## 实现边界

在现有 Expo / React Native 架构中建立可复用的颜色、排版、间距、圆角和交互状态变量。继续由 `ThemeContext` 提供主题，避免页面再次各自定义强调色。

通用层负责品牌页眉、分区标题、按钮、输入框、列表行和状态提示；外刊封面、生词释义、练习答案等领域组件继续放在对应功能目录。视觉组件接收数据和事件，业务 hook 负责请求、持久化与导航。

数据流沿用现有 API → 功能 hook／页面状态 → 视觉组件。客户端契约、认证、复习计划、生成状态机和数据存储逻辑维持现有行为。本次视觉设计不要求数据库迁移。

字体可通过项目已有的 `expo-font` 加载本地资源，图片继续使用已有的 `expo-image`。实现方式参考 [Expo SDK 57 字体文档](https://docs.expo.dev/versions/v57.0.0/sdk/font/) 和 [Expo SDK 57 图片文档](https://docs.expo.dev/versions/v57.0.0/sdk/image/)。

## 状态与适配验收

- 统一初次加载、继续加载、空内容、请求失败、重试、已选中、禁用和提交中的表现。
- 图片失败显示刊物或品牌占位；字体失败回退；请求失败沿用中文提示并保持用户输入。
- 点击区域至少 44×44；不以颜色作为唯一状态标识；支持文字放大、安全区和键盘避让。
- 以 360、390、430 宽度及较宽 Web 视口检查溢出、标题换行、工具栏和底部安全区；同时检查浅深两套主题。
- 对现有主题、导航、词库、书架、阅读、登录、练习测试运行回归。只为出现行为变化的交互补充有意义的测试。
- 实施完成后运行 `npm run check` 和 Web 导出检查。Web 验证覆盖布局与可运行入口，依赖安全存储及原生模块的完整业务流程需在可用原生环境中验证，并如实记录验证范围。
