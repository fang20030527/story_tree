# 口语逐句发音评分设计

用户于 2026-10-02 确认使用 Speechace Basic 专用发音评测，目标是逐词纠音。本文件记录已确认方案；按用户的实施授权继续编码和验证。

## 体验与范围

沿用现有录音、回放和重录。在录音面板增加「发音评分」及英式／美式选择，用户点击后评测短录音；云端录音复用已有资产，本地录音先私有上传。结果包含句子发音分、逐词分数、音素反馈和最多三条中文练习提示。Basic 不请求 Pro 的流利度或语调接口。

评分每次针对一条英文字幕，最长 30 秒、最大 2 MiB。开始录音时固定字幕编号、英文原文和字幕版本；换句、改字幕、重录或切换账号不会将旧结果挂到新录音。旧录音没有字幕快照时提示重新录制，避免猜测其目标原文。未登录仍能本地录音，登录后可评分；登录用户的本地素材也能提交当前字幕快照进行短句评测。

## 接口与存储

新增 POST `/v1/speaking/pronunciation-assessments` 和 GET `/v1/speaking/pronunciation-assessments/:id`，复用 Bearer 身份、Idempotency-Key 和共享严格 Zod 契约。能力接口返回是否配置评测服务、时长上限和支持的口音。

客户端复用现有私有媒体上传。服务端校验录音归属、就绪状态、用途、字节数和时长；云端素材的原文和版本还须与服务端字幕一致。本地素材使用有长度限制的用户字幕快照。后端从自己的存储读取音频，不接受任意音频 URL。

Fastify 使用 Neon；正式 Web 的 Cloudflare 使用 D1 与私有 R2。分别增量增加评测表，共享 Speechace 适配器和输入／结果校验。评测结果独立于录音资产存活，替换录音后仍保留历史评分。未绑定的本地素材评测录音沿用临时上传 TTL，结果继续保存。

## 评测生命周期与幂等

单句评测同步调用上游，状态为 processing → ready 或 failed，避免为短请求增加第三套任务队列。读取音频整体最多 10 秒，上游请求及响应读取默认最多 20 秒，响应最大 1 MiB；服务中断后，超过 45 秒的 processing 记录转成可重试失败。调用上游前再次确认当前记录仍在有效处理期，已失效的旧读取不会产生新的评测调用。

数据库在事务中占有评测请求，使用录音资产、字幕快照和口音生成指纹。同一幂等键必须匹配相同请求；相同指纹已有成功或处理中记录时复用，只有占有新记录的一方调用上游。网络丢失重放原幂等键，不会再次评测。明确失败后，用户点击重试才创建新的尝试；上游超时后的重试可能再次计费，不自动重试。默认每账号每天最多 50 次新尝试，缓存命中和网络重放不计入。

## 服务配置与错误

服务端配置 SPEECHACE_API_KEY、SPEECHACE_REGION（默认 ap-southeast）、SPEECHACE_TIMEOUT_MS 和 SPEECHACE_DAILY_LIMIT。只允许官方区域端点，不将密钥放进 EXPO_PUBLIC_ 变量、客户端包、请求日志或错误响应。缺少配置时能力接口明确不可用，已有阅读和录音功能照常工作。

静音、不可识别音频、过长录音、错误字幕版本、额度耗尽、上游密钥错误、网络超时及无效评分结果返回稳定错误码和中文提示。不把缺失的词或音素评分当成 0 分；不使用转写文本自行伪造声学评分。

## 验收

覆盖契约边界、真实响应形状解析、无效上游结果、密钥脱敏、静音错误、幂等重放、不同键并发复用、账号隔离、字幕版本冲突、失败重试和录音快照绑定。运行工作区 check、Cloudflare 测试与类型检查、服务端构建、Web 导出和客户端密钥检查。没有 Speechace 凭证时使用注入的测试 provider，不宣称真实联调成功。
