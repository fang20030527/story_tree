# Cloudflare 免费媒体迁移实施计划

**目标：** 在免费套餐内让 2026 年外刊音频从 R2 播放，并发布插图与 Web 静态资源。

**架构：** 私有 R2 桶保存全部 2026 MP3；轻量 Worker 按文章 ID 提供 Range 音频；两个独立静态资源项目发布插图与 Expo Web。现有业务 API 和数据库保持在线，直到下一阶段迁移完成。

**全局约束：** 不升级付费计划；不删除 `D:/电脑操作/Economist_Audio/2025/` 或任何原始音频；不提交密钥；保留已有未提交改动；不对未匹配音频猜测文章。

## 任务 1：整理 2026 清单

- 修改 `scripts/import-economist-local-audio.py`，只扫描 2026，并更新 `audio-local.json`、`audio-local-report.json` 和服务端清单。
- 让客户端仅给 2026 文章返回原刊录音；2025 年文章继续可读。
- 记录 2,725 个源文件、2,674 个匹配项及 51 个未匹配项的核对结果。

## 任务 2：R2 上传与音频服务

- 新增可重复运行的上传脚本：枚举全部 2026 MP3，校验路径及大小，用稳定对象键上传并比较已有对象的 SHA-256 元数据，凭证只读本地环境变量。
- 新增 Audio Worker 与 Wrangler 配置，私有 R2 绑定只读，支持 GET、HEAD、206 Range、416 和 404。
- 让现有 API 在配置公开音频 origin 后临时重定向旧版客户端，同时保留开发环境本地读取路径。

## 任务 3：插图和 Web 静态部署

- 新增外刊插图和 Web 的 Workers Static Assets 配置；插图直接使用现有 17,164 个 WebP，Web 使用 Expo SDK 57 静态导出。
- 为客户端增加公开的媒体 origin 配置，缺省时仍用当前 API 地址。
- 更新中文部署说明和环境变量样例，写清免费额度、账号登录、构建变量与切换顺序。

## 任务 4：远端发布和交接

- Cloudflare 登录后核对账号 R2 现有用量与免费计划状态；如不足以容纳 2026 音频，不继续上传。
- 创建私有桶，上传并核对全部对象，发布 Audio Worker、插图与 Web，记录实际 URL。
- 单独提交本次迁移文件并推送当前工作分支；不包含工作区已有的其他修改。
- 汇报已上线组件、尚依赖 Render/Neon 的功能，以及后续全量 API/D1 迁移的具体阻碍。
