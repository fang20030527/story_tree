# 阅读与口语 Web 发布

用户明确授权将已确认的阅读／口语前端、口语后端和固定影片提交推送到远端 main，并部署正式 Web。

## 发布范围

- 「我的」标题结合阅读／口语切换，口语底部导航为素材、文件、我的，两个模式保留品牌 Logo。
- 口语素材库、文件导入、已有 SRT／VTT 字幕校正、逐句与 AB 循环、变速、字幕显示、录音回放、收藏笔记和练习历史。
- 订阅页面展示统一权益；网页月卡／年卡／终身价格为 ¥19／¥128／¥198，苹果端为 ¥22／¥148／¥228。
- 三部固定电影：阿甘正传、泰坦尼克号、The Odyssey，共 5,046 句电影字幕，供所有用户在「素材」查看；个人文件与记录按账号隔离。

自动字幕、AI 发音评分、真实会员收款和 YouTube 嵌入播放器仍沿用现有功能范围，本次发布不把规划入口标记成已经完成的真实服务。

## 生产架构

正式入口为 `https://blackholeenglish.com`，Web 与 API 使用原来的 Cloudflare Service Binding。API 继续写入 D1 `waikan-core`，只增量应用 `0005_speaking.sql` 的六张表；没有从 Neon 导入或覆盖生产账号、阅读记录。

固定影片、原始 SRT 和目录位于私有 Standard R2 桶 `waikan-2026-audio`。新增七份供 Worker 读取的摘要／详情对象，详情按需加载；三部影片实际大小和原有 SHA-256 元数据核对通过。外刊音频继续保留原有路径。正式站跨域播放和直传所需的 CORS 已配置，桶公共访问保持关闭。

个人媒体使用签名直接上传 R2，确认接口验证所有者、真实大小、类型、文件头、ETag 和浏览器读取时长；不经 Web 网关转发整部影片。单文件上限 3 GiB、账号已绑定及未过期预留合计 10 GiB。PUT 绑定字节数和 `If-None-Match:*`，同一对象禁止覆盖；客户端不把账号令牌发送到 R2。Cloudflare 不运行 FFprobe，完整服务端音轨探测仍属于 Fastify 路径。

口语 JSON 请求转交既有 SQLite Durable Object，D1 事务检查幂等、修订号、资产归属和到期时间。固定字幕始终作为原文，个人校正只覆盖该账号；旧练习不会让累计时长和最新位置倒退。清理器只处理过期且未绑定的个人对象。
